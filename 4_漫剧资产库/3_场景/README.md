# 3_场景 · 场景板资产库（待补）

> 状态：**空库**。本目录用于存放做漫剧时可复用的场景板，与 `1_人物三视图/`、`2_人物音色/` 并列，作为「选场景 / 锁场景一致性」的参考资产。

## 放什么

- 场景板 PNG：每个场景一份，正/侧/俯或全景+关键角度，供 N4 出图与 H3 出片挂参考图锁场景。
- 命名建议：`<场景名>/<角度或版本>.png`，如 `教室/白天-全景.png`、`走廊/夜晚-侧面.png`。
- 可选：`提示词.txt` 记录出图模板与负向词（参照 `1_人物三视图/提示词.txt` 写法）。

## 怎么补

1. 用 `<资料库根>/2_工作流/02-漫剧/01-分镜图片/` 下的场景板工作流出图，或 `short-drama-image-prompts` skill 生成提示词后出图。
2. 出图后把成图按上面命名放进本目录。
3. 在 `7_经验库/工作流优化经验库.md` 追加本次场景一致性的坑与解法。

## 注意

- 本目录是**公共参考资产**，不是某项目的专属产物；项目实际用的场景板随项目放进 `<资料库根>/5_漫剧/<项目名>/`。
- H3 对白镜挂参考图过多会串味，场景板建议一镜一场景、与人物板分开挂。
