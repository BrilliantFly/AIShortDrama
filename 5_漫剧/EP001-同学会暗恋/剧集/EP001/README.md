## 目录树与用途

```
剧集/EP001/
├─ 剪辑单.md                       ← 人工定稿（草稿为每个 CUT 整段保留）
├─ 视频提示词.md                   ← MOTION-ID 骨架，供 edit_tool.py check 核对来源 ID
├─ 剧本.md / 分镜.md / 视觉设定.md  ← 有 --drama-dir 时复制真实文档，否则占位
├─ 制作成果/
│  ├─ videos/MOTION-EP001-*.mp4    ← 逐镜片段（未拼接）；来自 render_submit 的 -1 版优先
│  ├─ 片段清单.csv
│  ├─ 成片版命令.md                ← 成片版三条命令，参数已填好
│  ├─ 两版产物说明.md
│  └─ 成片/                        ← 混音成片 + 字幕 + 验收报告 + qc_report.json
```

## 关键点

- `edit_tool.py check` 会核对剪辑单里每个 `MOTION-...` 来源 ID 是否存在于 `视频提示词.md` 的 `## MOTION-...` 标题（且 `- 分镜：SHOT-...` 行供解析）。片段版必须同时生成该骨架，否则报「来源不在《视频提示词.md》中」。
- 路径全部相对本工作区；ComfyUI 安装根用环境变量 `COMFYUI_ROOT`，见 `<资料库根>/路径约定.md`。
- 完整命令与步骤见 `<资料库根>/6_剪辑/剪辑目录README.md` 第六、七节。
- 本工作区随仓库走（clone 到任何电脑都可用）；真实 mp4/成片等大文件按 `.gitignore` 规则管理，不强制入库。
