# 东方不败名场面桥段 · 流程测试分镜

> **测试声明**：本分镜仅借电影《笑傲江湖之东方不败》的**桥段类型与情绪基调**（竹林独酌／湖心琴箫／崖顶决战／独孤破招／日暮归隐）做流水线验证。角色、台词、造型、场景、事件均为本测试原创，不复刻电影的具体画面、台词或人物造型。

---

## SHOT-S001 竹林独酌·风过

- 镜号：S001
- 镜型：SOLO
- 时长：5.167 秒（124 帧，5+17×7）
- 景别：全身中景，人物从头到鞋底完整入镜，竹根与落叶可见
- 出场设定：无名客，30 岁，月白长衫、青布鞋；独立于竹林空地，右手执酒壶，左手垂在身侧。
- 对位：无第二人；两株粗竹一左一右固定，空地留白。
- 场景：夜竹林，两株粗竹位置固定，冷月光自竹梢斜落，地面落叶与湿土可见。
- 对白：「这酒，敬无名。」
- 终点：酒壶倾出一线，酒液将落未落，一片竹叶擦过肩头。

【导演运镜诊断】
- 焦点：执壶的手 → 将落的酒线。
- 运镜意图：**缓推**（very slow push），从全身中景极缓推进半步，终点仍保留鞋底与竹根。
- 落点：酒线离壶口一瞬，竹叶擦肩而过。
- 纪律：推轨极慢，不切镜，不改到更近景别；全身露脚踩地是硬约束。

## SHOT-S002 湖心琴箫·未终

- 镜号：S002
- 镜型：DUO
- 时长：4.250 秒（102 帧，17×6）
- 景别：全身中景，两人同框从头到鞋底完整入镜，小舟木板可见
- 出场设定：白衣琴师，28 岁，素白长袍、黑布鞋，坐于舟首抚琴；青衫客，31 岁，青灰长衫、布履，坐于舟尾按箫。
- 对位：两人隔一张矮几相对，机位守 180° 轴线同侧，固定侧面双人中景。
- 场景：夜湖心小舟，两侧芦苇位置固定，冷蓝雾气贴水面，舟内一盏油灯暖光。
- 对白：「一曲未尽，人已千里。」
- 终点：琴弦停振，箫声收尾，水面灯影碎开。

【导演运镜诊断】
- 焦点：琴弦 → 水面碎开的灯影。
- 运镜意图：**机位锁死**（相机固定），以水波与灯影代替运镜。
- 落点：琴弦停振一瞬，灯影被水波切断。
- 纪律：机位锁定，无镜头位移、不切镜；画面变化只由水波与灯火完成，音色承载情绪。

## SHOT-S003 崖顶决战·对峙

- 镜号：S003
- 镜型：DUO
- 时长：5.667 秒（136 帧，17×8）
- 景别：全身中景，两人同框从头到鞋底完整入镜，崖顶石面可见
- 出场设定：红衣客，30 岁，绯红长袍、黑靴，右手两指并拢；青衫客，31 岁，青灰长衫、布履，长剑斜垂。两人等景别等高度正面相对。
- 对位：两人隔三步正面对峙，机位守 180° 轴线同侧，固定正面双人中景。
- 场景：崖顶石台，两块断石位置固定，冷青天光自云隙落下，崖边劲风卷衣袂。
- 对白：「你的剑，太慢。」
- 终点：两指夹住剑锋，风停一拍，衣袂仍在动。

【导演运镜诊断】
- 焦点：剑锋 → 夹住剑锋的两指。
- 运镜意图：**缓推**（very slow push），从全身中景极缓推进，终点仍保留两人鞋底与崖顶石面。
- 落点：两指夹住剑锋的一瞬，风声骤停。
- 纪律：推轨极慢，不切镜，景别不动；对抗靠等景别等高度与停顿，不靠动作幅度。

## SHOT-S004 独孤破招·疾影

- 镜号：S004
- 镜型：DUO
- 时长：4.958 秒（119 帧，17×7）
- 景别：全身中景，人物从头到鞋底完整入镜，青石地面可见
- 出场设定：青衫客，31 岁，青灰长衫、布履，长剑出鞘连挑三式；红衣客，30 岁，绯红长袍、黑靴，闪身后退。
- 对位：攻守两相位在一镜内交替，机位守 180° 轴线同侧，固定侧面双人中景。
- 场景：崖顶石台延伸的青石地面，两块断石位置固定，冷青天光方向不变，扬尘贴地。
- 对白：无。
- 终点：剑尖悬停，红衣客袍角扫过扬尘，尘粒落定。

【导演运镜诊断】
- 焦点：剑尖连挑的三式轨迹 → 悬停的剑尖。
- 运镜意图：**机位锁死**（相机固定），以剑势与扬尘代替运镜。
- 落点：剑尖悬停、尘粒落定一瞬。
- 纪律：机位锁定，无镜头位移、不切镜；疾影靠主体速度与扬起又落定的尘，镜头一动就散。

## SHOT-S005 日暮归隐·远山

- 镜号：S005
- 镜型：DUO
- 时长：5.875 秒（141 帧，5+17×8）
- 景别：全身中景，两人同框从头到鞋底完整入镜，山径土面可见
- 出场设定：青衫客，31 岁，青灰长衫、布履；白衣琴师，28 岁，素白长袍、黑布鞋。两人并肩背对镜头走向远山。
- 对位：两人并肩同向，机位守 180° 轴线同侧，固定背面双人中景。
- 场景：日暮山径，两株歪脖松位置固定，暖橙残阳自山口斜照，土面长影拖向镜头。
- 对白：「江湖远，且归去。」
- 终点：两人影没入山口，残阳最后一束光落在空径上。

【导演运镜诊断】
- 焦点：并肩的肩线 → 拖向镜头的两道长影。
- 运镜意图：**缓推**（very slow push），从全身中景极缓推进，终点仍保留两人鞋底与土径。
- 落点：长影没入山口、残阳收束一瞬。
- 纪律：推轨极慢，不切镜，景别不动；离场靠背影与负空间，不靠机位升高。

## 全场情绪曲线诊断

1. S001 竹林独酌·孤独：焦点从执壶的手移到将落酒线，落点＝酒液离壶、竹叶擦肩；缓推极慢，靠靠近制造"有人陪却无人"的空。
2. S002 湖心琴箫·亲密：焦点从琴弦移到碎开灯影，落点＝琴弦停振；全场唯一彻底固定机位之一，靠音色与水面光把距离缩短。
3. S003 崖顶决战·对抗：焦点从剑锋移到夹剑的两指，落点＝风声骤停；等景别等高度＋缓推，靠停顿而非幅度制造压迫。
4. S004 独孤破招·紧张：焦点从三式轨迹移到悬停剑尖，落点＝尘粒落定；第二处固定机位，与 S003 的缓推形成对照。
5. S005 日暮归隐·悲伤中的释放：焦点从肩线移到拖向镜头的长影，落点＝残阳收束；缓推极慢，背影与负空间把情绪松开。
- 情绪曲线：孤独 → 亲密 → 对抗 → 紧张 → 悲伤释放。整场按「收紧（S001 缓推靠近）→ 松开（S002 固定留白）→ 再收紧（S003/S004 对抗与疾影）→ 释放（S005 缓推没入山口）」走法，靠运镜有无与光的变化打动人，而不是靠切镜数量。
- 运镜节奏：缓推 / 固定 / 缓推 / 固定 / 缓推 交替，两个固定镜（S002 湖心、S004 破招）分别对应"静到极致"与"动到极致"，构成全场的呼吸点。
