## 5. 测试中发现并修正的四个输入写法问题

均为素材写法触发门禁，非脚本 bug，修完全绿：

1. **CAST 词表**：服装写 `robe` / `cloth shoes` 不被 `check_castset_slot` 的 `CLOTHES_RE` 识别（它认 `coat`/`boot`）→ 改 `cloth boots` / `black leather boots`。**教训：武侠服装也要在描述里落一个门禁认的英文锚词。**
2. **SET 地面锚**：竹林/山径场景缺 `floor` 字样 → 补 `stone floor` / `dirt floor`。**教训：场景板要写"地面"且带 floor，否则 r2v 自由生成空间。**
3. **CSV 镜号**：CSV 全写 `[Shot 1]`，`check_prompt_content` 要求 CSV 镜号 = shot_id 数字（S002→`[Shot 2]`）→ 按行改。**注意视频提示词.md 侧仍是全 `[Shot 1]`（single 档逐镜独立出片），两层口径不同，勿混。**
4. **Audio 定义**：在 `subject_definitions` 行内手写 `<Audio 1> is the voice-timbre reference for the speaker.`，桥接器不补带 `(Sx)` 绑定的标准定义，lint 判「缺唯一语义源定义」→ 移除手写定义，让桥接器自动生成 `<Audio 1> is ... for <Subject 1> (S1).`。**教训：Audio 定义不要手写，交给桥接器。**

### 一个桥接器边界（非本次阻断，建议后续加固）

时长写 `5.875 s`（小数 + 英文 s）时，`md_to_h3_lint` 会 FAIL 两类：`packed runtime = sum(int(duration))` 得整数 23s，而 unit 时长和 25.917s 对不上；且中文块 `%.1f` 把 5.875 进位成 5.9 超出单镜 5.875。EP001 用整数秒、WUXIAFLOW 用中文「秒」都规避了。**建议**：桥接器对 packed runtime 改用浮点求和、镜头终点用 `min(d, round(d,1))` 防越界，或在文档写明时长行统一用中文「秒」。本次已回归中文秒写法通过。

S="1_AI漫剧全流程解决方案/AI漫剧全流程自动化方案"
