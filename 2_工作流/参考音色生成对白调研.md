# ComfyUI 参考音色生成自然对白工作流整理

## 一、总体思路

在 ComfyUI 中用参考音色生成自然对白，目前比较成熟、对“自然度”支持较好的路线主要有两条：

1. **CosyVoice3 的 Dialog 节点**：上手直接，参考音频要求宽松，适合快速生成多说话人对白。
2. **Speech-God**：专为角色对白设计，角色库和情感控制更完整，适合固定角色反复使用。

此外还有多种核心引擎和聚合套件可选，下文一并整理。

---

## 二、参考音频预处理：决定“自不自然”

无论使用哪个引擎，参考音频的质量直接决定克隆结果的像真度。推荐规格：

- **格式**：24 kHz 采样率、**单声道 WAV**。MP3 的高频压缩会丢失音色细节，不建议使用。
- **时长**：**3–10 秒**是大多数模型的最佳区间；CosyVoice3 最低 3 秒可用，IndexTTS2 甚至支持 0.25 秒，但 5–10 秒通常更稳。
- **内容**：一句话通顺的人声，语气自然，**不要大喊或刻意压嗓**。背景无底噪、无喷麦、无回声。
- **底噪处理**：如果素材有底噪，可先用 `AudioCleanupNode` 做预处理：
  - `denoise_strength` 从 **0.5** 起步；
  - 背景噪声明显时推到 **0.7–0.8**；
  - 频率范围保留人声频段，如 **100–8000 Hz**。

## 三、路线一：CosyVoice3 Dialog

CosyVoice3 的 Dialog 节点支持**最多 4 个说话人**。只需按 `SPEAKER A:` / `SPEAKER B:` 的格式写好脚本，再为每个说话人各接一段参考音频，节点会自动路由并合成完整对话。

### 3.1 最小工作流

```text
LoadAudio (参考音频 A) ──┐
LoadAudio (参考音频 B) ──┤
                         ├──► CosyVoice3 Dialog ──► PreviewAudio / SaveAudio
Text (脚本，含 SPEAKER 标签) ──┘
        ▲
Model Loader (Fun-CosyVoice3-0.5B)
```

### 3.2 节点连接要点

1. **FL CosyVoice3 Model Loader** 选择 `Fun-CosyVoice3-0.5B`。这是推荐模型，约 2 GB；CosyVoice-300M 效果较差，不建议使用。
2. 每个 `LoadAudio` 接入对应说话人的参考音频。**CosyVoice3 不要求手动填写参考文本**，节点内部会用 Whisper 自动转写。
3. 文本框中按格式写脚本，例如：

   ```text
   SPEAKER A: 你真的要现在走吗？
   SPEAKER B: 再不走就来不及了。
   ```

4. Dialog 节点的 `speed` 可以先保持 **1.0**；`seed` 固定一个值（如 42）方便复现，不满意时再换 seed 重试。

### 3.3 自然度调节

CosyVoice3 本身的语调自然度已经不错，但对白的“戏剧感”可以靠在脚本里加入**短停顿**来提升。

- 如果脚本支持停顿标记，可以在句子之间插入微小停顿。
- 如果节点不解析停顿标签，可以把长句拆成短句分别生成，再用音频拼接节点合并。

## 四、路线二：Speech-God

Speech-God 是基于 F5-TTS / Fish Speech 的**角色对白专用套件**。它的优势在于把“角色”作为一等公民：每个角色可以绑定独立的参考音频、音色参数、情感混合，生成时自动按 `[NAME]` 标签路由台词。

### 4.1 核心链路

```text
Speech-God Loader (引擎选 f5-tts)
        ↓
Speech-God Character (角色A：接参考音频 → voice ref)
        ↓
Speech-God Cast (把角色A、角色B…打包)
        ↓
Speech-God Generate (脚本中含 [NAME] 标签)
        ↓
Speech-God Post Process (降噪 / 压缩 / 去呼吸 / 均衡)
        ↓
Speech-God Export (wav / flac / mp3)
```

### 4.2 关键参数

- **引擎**：F5-TTS 是默认且推荐的首选，零样本克隆质量好。安装只需 `pip install f5-tts`，模型约 1.4 GB 自动下载。
- **角色定义**：每个 `Speech-God Character` 可以挂接**独立的 voice ref 和 emotion ref**。如果希望音色和情感分开控制，分别给两段音频即可。
- **情感混合**：`Speech-God Emotion Blend` 可以把不同情绪按比例混合，例如 70% happy + 30% excited，再接入 Character 节点。这是 CosyVoice 路线目前没有现成等价物的地方。
- **后处理**：`Speech-God Post Process` 默认包含降噪、归一化、压缩和去呼吸，**建议保持开启**，它能明显削掉克隆 TTS 常见的“电子感”和呼吸瑕疵。
- **多角色扩展**：Cast 节点支持**链式串联**，超过四个角色时继续接下一个 Cast 即可。
- **角色保存**：如果需要固定几个角色的声音反复出现在不同场景里，可以用 `Speech-God Save Character` 把角色配置和音频参考存成：
  - `characters/<name>.json`
  - `<name>.voice`

  下次直接加载，不用重新调参。

## 五、文本层面：让对白更“像人说话”

克隆模型给的是音色，**语气和节奏主要靠文本结构**来引导。建议在文本层面做三件事。

### 5.1 拆短句

不要让模型一口气读长段。过长的文本会导致自然度下降、语调趋平。对白尤其如此——真实对话本来就是短句交替。

### 5.2 用停顿标记制造呼吸感

部分节点支持在脚本中插入精确停顿，例如 `[pause:1.2]` 插入 1.2 秒静音。

如果所用节点不支持停顿标签，可以拆句后分别在句尾留白，再拼接，效果接近。

### 5.3 必要时调低随机性

如果生成结果偶尔出现奇怪的语调跳跃，可以把 `temperature` 或 `top_p` 适当调低。

例如：

- `temperature` 从 1.0 降到 **0.7–0.85**，可以减少异常韵律；
- 但调得过低会变得死板，建议小幅试探。

## 六、两条主流路线选型对比

| 对比项 | CosyVoice3 Dialog | Speech-God |
|---|---|---|
| **最适合** | 一次性多说话人对白，快速出结果 | 固定角色反复使用，需要情感分层 |
| **参考音频** | 3–30 秒，最佳 3–10 秒；无需手动转写 | 每个角色独立挂接；F5-TTS 自动转写 |
| **多角色上限** | 4 人 | 通过 Cast 链式扩展，无硬上限 |
| **情感控制** | 主要靠脚本和语速 | Emotion Blend 比例混合，更细 |
| **后处理** | 需自行接降噪/保存节点 | 内置 Post Process，默认可用 |
| **上手难度** | 较低，节点少 | 稍高，但角色管理更系统 |

**选择建议：**

- 如果只是想做一段两人或三人的对白试听，**从 CosyVoice3 Dialog 开始**最快。
- 如果已经在做系列内容、有固定“演员表”，**Speech-God 的 Character + Cast + Save Character** 会省下大量重复调参的时间。
- 两条路线都建议把参考音频按前面的规格先过一遍，自然度的起点会高不少。

## 七、其他可选方案

除了 CosyVoice3 和 Speech-God，ComfyUI 生态里还有不少音色克隆与对白生成方案，侧重点各不相同。下面按**核心引擎**和**聚合套件**两条线梳理。

### 7.1 核心引擎

#### ByteDance Seed Audio 1.0（ComfyUI 内置节点）

- ComfyUI 的**官方内置节点**，开箱即用，不需要额外安装社区插件。
- 独特之处在于**单一提示词就能同时生成语音、音效和背景音乐**，适合需要完整音频场景的对白片段。
- 音色克隆最多支持 **3 段参考音频**，在 prompt 中用 `@Audio1`–`@Audio3` 标记。
- 单次最长生成 **2 分钟**音频。
- 支持**从角色图片推导音色**的模式，对数字人视频很友好。

#### Qwen3-TTS（阿里通义）

- 对中文和方言支持很好，覆盖 10 种语言。
- **3 秒以上**参考音频即可克隆。
- 内置 **RoleBank 角色库**和 **AdvancedDialogue 多角色节点**。
- 脚本里支持 `[开心]` 这类情感标签和 `[pause:1.2]` 毫秒级停顿解析。
- 可以直接在单个节点里编排多角色对白并自动拼接。
- 克隆的 Prompt 可以保存复用，适合需要**反复使用同一批角色**的场景。

#### IndexTTS 2 / 2.5

- 零样本克隆。
- **独特优势是情感可控**：除了参考音色，还能额外接一段“情感参考音频”或情感向量，让克隆出的声音带上指定的情绪色彩。
- 社区节点比较成熟，有现成的工作流 JSON 可以直接拖进 ComfyUI 导入。

#### Chatterbox

- 有一个官方 **`FL_ChatterboxDialogTTS`** 节点，专为**多说话人对白**设计。
- 配合 `LoadAudio` 加载每位说话人的参考音频，流程很直观。
- 适合播客、有声书这类需要清晰区分说话人的场景。

#### Fish Audio S2 Pro

- 支持 **80+ 语言**和丰富的情感标签。
- 有配套的 ComfyUI 节点 `ComfyUI-FishAudioS2`。
- 适合需要**多语言或强情感表现力**的项目。

### 7.2 聚合套件

#### TTS-Audio-Suite

如果不想为每个引擎单独装插件，**TTS-Audio-Suite** 是目前比较全的选择。

- 集成了 Higgs Audio、IndexTTS、Chatterbox、Fish Audio、VibeVoice 等多个引擎，统一在同一个套件里切换和管理。
- Higgs Audio v3 在它里面支持原生内联标签，例如：
  - `<|emotion:amusement|>`
  - `<|style:whispering|>`
- 零样本克隆和 SRT 时间轴、角色切换也都有覆盖。

### 7.3 其他值得了解的选项

#### VoxCPM

- 除了克隆，还内置 **LoRA 微调训练**能力。
- 可以在 ComfyUI 里直接用 10 分钟左右的数据训练角色音色。
- 适合对某个声音有极致定制需求的情况。

#### ElevenLabs（Partner Node）

- 商业闭源方案，克隆质量和自然度是顶级水平。
- 有专门的 **Text to Dialogue** 多说话人对白节点。
- 注意它是付费的 Partner Node，不是本地免费运行。

#### MiniMax H3

- 走的是**生成式音频**路线，不是确定性音素 TTS。
- 有双人对白、长文本控制、ADR 等实验性工作流。
- 部分能力，如严格高保真克隆、精确情绪控制，还在验证阶段。

#### AuK（腾讯混元）

- 完全本地的语音生成/编辑模型。
- 提供 BF16 / INT8 / W4A8 等多档量化，适合显存有限但想跑本地方案的用户。
- 注意其 Prompt 遵循度因任务而异：克隆和 TTS 相对可靠，部分编辑任务需要多次重试。

#### GPT-SoVITS（Anomalous TTS）

- 如果已经有训练好的 GPT-SoVITS 角色模型，可以用这个节点直接加载。
- 支持多句生成、情绪切换和插入停顿。
- 不需要额外装整合包。

## 八、快速选型建议

| 需求 | 推荐方案 |
|---|---|
| 想开箱即用 | **Seed Audio 1.0**（ComfyUI 内置节点） |
| 中文/方言 + 角色库 | **Qwen3-TTS** |
| 需要情感可控克隆 | **IndexTTS** |
| 多语言 + 强情感标签 | **Fish Audio S2 Pro** |
| 想一个插件覆盖多引擎 | **TTS-Audio-Suite** |
| 两人或三人对白快速试听 | **CosyVoice3 Dialog** |
| 系列内容、固定角色反复使用 | **Speech-God 的 Character + Cast + Save Character** |
| 显存有限但想本地运行 | 可关注 **AuK** 等量化方案 |
| 需要训练专属角色音色 | **VoxCPM** 的 LoRA 微调 |
| 已有 GPT-SoVITS 模型 | **Anomalous TTS** 节点加载 |

**总体建议：**

- 先按规格处理好参考音频，这是自然度的起点。
- 快速试听多说话人对白，优先用 **CosyVoice3 Dialog**。
- 固定角色、长期系列内容，优先用 **Speech-God**。
- 需要中文角色库、情感标签、多语言或统一多引擎管理时，再从 Qwen3-TTS、IndexTTS、Fish Audio S2 Pro、TTS-Audio-Suite 等方案中按需选择。
