# 11 · H3 导演台 T8 曜石

> 上游：`github.com/T8mars/comfyui-minimax-h3-audio-T8`（国内镜像 `gitcode.com/gh_mirrors/co/comfyui-minimax-h3-audio-T8`）
> 收录时间：2026-11-16 · 来源：main 分支浅克隆快照

这不是一套工作流，而是 **H3 音视频节点包（14 个节点）+ 一套独立 UI 导演台**。前端是一个跟 ComfyUI 画布并列的网页工作台：左边镜头列表、中间提示词编辑、右边素材区，像剪辑软件一样排片。节点包里有 100 类、3000+ 个示例 JSON，是全库里体量最大的一份。

## 一、入口

`00-入口-曜石导演台Starter/2026-09-20_H3_Obsidian_Director_Starter.json`

拖进 ComfyUI → 点节点上的「打开曜石导演台」。装好插件后，ComfyUI 左侧栏还会直接出现一个独立的「T8 曜石导演台」入口，不走工作流。

> 这个入口 JSON 是**干净模板、不带占位素材**，别直接跑示例里的占位文件，先把模型和素材换成自己的。

## 三、三种素材用途（曜石导演台的核心）

| 用途 | 说明 |
|---|---|
| 原音驱动 | 选一段独立录音，驱动口型并按原声交付 |
| 参考音色 | 用参考音频的新音色念新台词，不贴回原声，不承诺声纹完全一致 |
| 视频自带音轨 | 参考视频自身的声音直接参与生成映射 |

提示词里输入 `@` 可按素材名或 `image/video/audio` 编号快速插入引用，↑↓ 选择、Enter 插入。

## 四、工程化能力（这套最值钱的地方）

- **按顺序生成全部**：提交前冻结项目快照，逐镜执行，任一镜失败即停，不会重复提交；
- **A/B 对比**：同一镜两版并排播放，确认后「采用此版」，旧成片不会被悄悄替换；
- **取帧接下一镜**：从成片提原尺寸 PNG 当下一镜首帧；
- **整片串播 + 导出 MP4**：独立 CPU FFmpeg 导 24fps H.264 + AAC，不占生成队列；
- **工程包 ZIP**：带素材与采用成片的完整工程，可换机器，导入时重新绑定素材身份；
- **双采样**：一个底模分两阶段 LoRA 链，先低分辨率再学习型 3D latent 放大；
- **文本分镜导入**：粘 `# 镜头名 | 时长` 格式的脚本批量追加镜头，不猜自然语言时长。

## 五、几个硬性约束

1. **必须装插件**：`ComfyUI Manager` 搜 `MiniMax H3 Audio T8`，或 `git clone https://github.com/T8mars/comfyui-minimax-h3-audio-T8.git`。导演台是前端扩展，**装完要完全退出 ComfyUI 重启 + 刷新浏览器**，光刷页面不生效。
2. **本机 0.30.2 打不开**：这套要用较新的 ComfyUI（H3 原生节点 + Loop + 新版前端），装之前先升级。
3. **单文件上传上限 1 GiB**，超了直接报错不截断，先转成标准图片/MP4/WAV。
4. **保存是显式的**：「保存项目」必须点；草稿是按标签页的，另一个标签页存过会弹冲突提示而不是静默覆盖。
5. 三个导出文件不等价，别混：
   - `director.project.json` —— 可编辑工程（含提示词草稿与参考映射）
   - `director-d1-preflight.workflow.json` —— 原生 CPU 图，可在画布打开
   - `director-d1-preflight.api.json` —— 上面那张图的 API 快照
   都不是 GPU 生成配方；生成走 D2，通过独立 Core 服务提交。
6. 预检通过只代表工程和参考能编译，**不代表模型兼容、不代表显存够、不代表成片好看**。
