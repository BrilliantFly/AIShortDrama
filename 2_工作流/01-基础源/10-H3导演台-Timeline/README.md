这套的技术路线和另外两套不同：它不是「生成完再拼」，而是**直接把上一段采样出来的 AV Latent 尾部喂给下一段**，中间不经过解码→重编码。所以接缝的成因被从源头掐掉了大半，再叠 Drift-Control 遮罩和 Soft AV 音频过渡来收尾。

## 二、一套工作流覆盖的 7 类任务

切换任务只靠三样东西：素材规划台里放什么、GEN 时间框拉多长、提示词写什么。**节点连线一次接好之后不用再动。**

| # | 任务 | 怎么配 |
|---|---|---|
| 1 | 文生视频 | 不上传素材，填全局提示词，GEN 框即成片长度；内部自动建标准 H3 空 AV Latent |
| 2 | 参考图生视频 | 图片箱放参考图，支持单段/多段 |
| 3 | 图片 + 音频参考 | 图 + 音频组合，多段可连续生成 |
| 4 | 数字人对口型 | 音频设「原音锁定」，按段注入 AV Latent，成片保留原声 |
| 5 | 视频可编辑参考 / 编辑 | 视频放时间线，青色选区覆盖要重写的区间 |
| 6 | 人物替换 | 原视频设「可编辑参考」，不硬锁原人物 |
| 7 | 动作迁移 | 参考视频当动作 Guide，图片箱放角色素材 |

### 视频素材的三种用途（最容易搞错的一处）

- **固定 Guide** —— 重叠部分按生成时间位置固定，适合续写、保运动；
- **可编辑参考** —— 只作参考，不硬锁原人物，适合换人或换风格；
- **仅固定边界** —— 只固定重叠区首尾帧。

## 三、长视频四步

1. 设分段数量 → 点「更新分段」，得到 GEN1…N 时间框；
2. 拖 GEN 框定每段长度与相邻重叠（**必须是正重叠**，0 帧重叠 = 两段独立生成）；
3. 每段分配素材（图/音频/相交的时间线视频），填全局或分段提示词；
4. 连运行：「分段规划」→「有限分段采样」，一次执行完成逐段生成与合并。

### 底层参数（照抄，别自己算）

- 帧长必须落在 **`5 + 17n`** 网格上（如 124 帧 ≈ 5 s @ 24fps），插件会自动对齐；
- 请求的重叠会被对齐到合法网格：**请求 24 帧 → 实际 22；请求 48 → 实际 39**，载波、裁剪、合并三步用同一个对齐值；
- 每段共用同一个 seed；
- Drift-Control 的遮罩按对齐后的重叠视频 token 数和采样器 sigma 曲线自适应，**4 步/8 步加速调度也算在内**；
- 音频续接：重叠区原样保留到最后 8 个音频 latent tick，再用半余弦 Soft AV 遮罩释放给新生成音频；
- 分段上限 64 段，实际受显存/内存限制，**先用 2~3 段低分辨率验证再放大**。

## 四、SelfLift 二采（75% 低清 + 25% 高清）

勾「开启二采」→ 选 `ComfyUI/models/latent_upscale_models/` 里的 H3 Latent Upscaler → 填高清采样步数。
总步数 8 时填 2，实际执行 `6 步低清 + Latent 放大 + 2 步高清`。高清步数必须 > 0 且 < 总步数。
二采不是逐段放大：段与段之间同时延续低清 latent 尾部和最终高清 latent 上下文，两个阶段各跑一次 Drift-Control。

作者实测：`1536×832 / 29 秒` 约 10 分钟直出。

## 五、原音锁定（数字人 / 唱歌）

独立音频设为原音锁定后，原始波形按时间线切开、逐段注入每个分段的 AV latent，**音频去噪遮罩置 0**，也就是让原信号直接穿过去而不是重新生成。成片再还原成连续原声轨。
实测音频内容与时序保持 99%+ 一致；最终 MP4 封装可能按保存节点设置重新编码一次音频。

## 六、和另外两套的取舍

| | 本套（Timeline） | 09 · NG 版 | 11 · T8 曜石 |
|---|---|---|---|
| 接缝处理 | latent 直接续接 + Drift-Control | 规划器切段 + seam-aware 拼合 | 导演台编排，走原生 expand |
| 上手成本 | 中（参数要理解） | 低（9 个模板照着改） | 低（有独立 UI 面板） |
| 长片证据 | 52.6 s / 1263 帧 单次执行 ×2 | 3 分钟 / 1 分钟示例 | 多段 + 整片 MP4 导出 |
| 中文文档 | 全中文 | 英文 | 中文 |
