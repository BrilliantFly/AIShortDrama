## 为什么备份

用户 2026-11-21 二次确认：后续出图实际用的不是这些原版卡（角色板已由出图链承接），
因此**把原版卡放备份，把实际用的平铺到 `01-分镜图片/` 根下并合理命名**。
其中场景板 / 道具板 / 人像正侧这 4 类**仍要用**（出图链不产 `PLATE`/`PAIR`/人像单图），
所以以「现役副本 + 规范命名」形式留在根下，原件在此留档。

## 回退方法

- 想用旧文件名：直接把本目录对应文件复制回上一级 `01-分镜图片/`（现役同名文件需先移走或改名）。
- 想用出图链原始命名：从 `_原N4出图链-三视图/` 复制，或从
  `2_工作流/01-基础源/06-QwenEdit-三视图/`（**源目录，从未改动**）复制。
- 另有同 MD5 副本：`2_工作流/归档/workflows/02-漫剧/01-分镜图片/` 的 5 个 `28张-*.json`。
- ComfyUI GUI 侧同结构：`.../workflows/01-分镜图片/_原版卡备份/`。
