# 七个工作流作用备注

> 更新时间：2026-11-21
> 本目录 7 张工作流卡的作用速查。详细操作步骤见 `N4出图链-使用说明.md`，目录重组说明见 `README.md`。

## 出图链（角色板 A1 -> A2，串行使用）

### 01-角色板-A1底板生成-ZImageTurbo.json
- **作用**：用 Z-Image Turbo 生成角色板的排版底板 —— 1344x768 画布上带预设分格版式的图（多格参考板框架）。
- **职责**：只管"排得整齐"，不负责人物长相。
- **参数族**：Z-Image Turbo（8 步 / cfg 1.0 / res_multistep+simple / shift 3 / 无负向）。

### 02-角色板-A2三参考换人-QwenEdit.json
- **作用**：用 Qwen-Image-Edit 接收 A1 的底板 + 2~3 张参考图，把底板里的人物统一换成目标角色的脸（锁脸）。
- **职责**：角色身份一致性的核心环节，保证角色板上每格都是同一张脸。
- **参数族**：Qwen-Image-Edit（20 步 / cfg 3-4 / euler / shift 3）。

## 出图链（三视图 B，独立并行，不依赖 01/02）

### 03-三视图-B独立电影合成-QwenEdit.json
- **作用**：用 Qwen-Image-Edit 从参考图直接合成电影感三视图（正面/侧面/背面），自带光影氛围调整。
- **职责**：独立出一张角色三视图设定图，不消费 A1 的排版底板，与角色板链路互不干扰。
- **参数族**：Qwen-Image-Edit。

## 原板卡（保留，出图链不覆盖的领域）

### 04-场景板-1344x768-ZImageTurbo.json
- **作用**：生成场景参考板 —— 某一场景（如"夜晚街道""办公室"）的 1344x768 横幅参考图。
- **用途**：供分镜和视频阶段保持场景一致。出图链不产场景图，此卡仍是主力。

### 05-道具板-1024x1024-ZImageTurbo.json
- **作用**：生成道具参考图 —— 关键道具（信物、手机、武器等）的正方形特写参考。
- **用途**：保证道具在多镜头中的一致性。

### 06-人像正面-832x1216-ZImageTurbo.json
- **作用**：生成角色正面单图（竖幅 832x1216）。
- **用途**：喂给 inswapper/换脸节点做参考脸，或作为 N4 资产库的 IMG-F 正面像。

### 07-人像侧脸-832x1216-ZImageTurbo.json
- **作用**：生成角色侧面单图（竖幅 832x1216）。
- **用途**：补齐侧脸参考（IMG-S），用于侧拍镜头的换脸参考和三视图比对。

## 一句话总结

- **01 -> 02** = 角色板一条龙（排版 -> 锁脸换人）
- **03** = 独立电影感三视图
- **04~07** = 场景、道具、正/侧脸四类单图资产，仍由原 ZImageTurbo 板卡负责
