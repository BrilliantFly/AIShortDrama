## 一、后续出图用哪 7 个（现役清单）

| 序号 | 文件名 | 用途 / 产物 | 引擎与参数 | 路线 |
|---|---|---|---|---|
| 01 | `01-角色板-A1底板生成-ZImageTurbo.json` | 三视图底板排版，输出 `底板-脚全`（要求全身、露脚/鞋/地面） | Z-Image Turbo **bf16** · 8 / cfg 1.0 / res_multistep+simple | **A①** |
| 02 | `02-角色板-A2三参考换人-QwenEdit.json` | 消费 01 产物 + `ref_band_flat` / `ref_face_hd`，三参考换人锁脸，输出 `参考板-换人成品` | Qwen-Image-Edit 2509 · 20 / cfg 3.0 / euler / shift 3 | **A②**（接 A①） |
| 03 | `03-三视图-B独立电影合成-QwenEdit.json` | 独立电影感路线：三视图条 + 表情条 → `合成参考板` | Qwen-Image-Edit 2509 · 双 KSampler 20 / cfg 4.0 / euler / shift 3 | **B（独立）** |
| 04 | `04-场景板-1344x768-ZImageTurbo.json` | 场景板 `*-PLATE` | Z-Image Turbo int8_convrot · 1344×768 | 单图 T2I |
| 05 | `05-道具板-1024x1024-ZImageTurbo.json` | 道具板 `*-PAIR` | 同上 · 1024×1024 | 单图 T2I |
| 06 | `06-人像正面-832x1216-ZImageTurbo.json` | 人像正面参考 | 同上 · 832×1216 | 单图 T2I |
| 07 | `07-人像侧脸-832x1216-ZImageTurbo.json` | 人像侧脸参考 | 同上 · 832×1216 | 单图 T2I |

**为什么是这 7 个**：出图链只产 `IMG-*-SHEET`（角色板 / 三视图 / 表情板），
**不产** `PLATE`（场景板）、`PAIR`（道具板）、人像正/侧单图；这 4 类目前仍只有
Z-Image Turbo 单图板卡能出，且主干 `工作流底座/n5_zimage_single.json`（N5 每镜起始帧）
与它们同族（**板帧同源**）。因此角色板入口切到出图链，4 个板卡保留现役。

**命名规则**：`序号-用途-路线/规格-引擎`。`A1/A2` 表示串行两步，`B` 表示独立并行路线；
引擎后缀区分 Z-Image Turbo 板卡族与 Qwen-Image-Edit 编辑族，避免参数跨族套用。
仅改**文件名**，7 个 JSON **内容一字未改**（工作流内部 SaveImage 前缀仍是 `28张/0X-*`
或 `底板-脚全` 等，不影响使用与既有产物）。

## 二、路线真相（重要）

**不是 `01→02→03` 三步连跑**：01 → 02 是串行（02 的 `LoadImage #10` 明确消费 01 产物
`底板-脚全.png`）；**03 是独立并行路线**，从自己的 `LoadImage`（目标人物照片）重新开始，
与 01/02 无连线，输出前缀也不同。两条路线按需二选一，或分别出图后人工择优。
完整链路、模型清单、参数分族、输入图准备见 **`N4出图链-使用说明.md`**。

## 六、怎么用

1. ComfyUI 侧边栏 Workflows → `01-分镜图片/`，直接点开 7 个现役 JSON（GUI 副本 MD5 一致）。
2. 路线 A：跑 01 → 输出改名 `底板-脚全.png` 放 `input/`；准备 `ref_band_flat.png` / `ref_face_hd.png` → 跑 02，得 `参考板-换人成品`。
3. 路线 B（独立）：换掉 03 的 `LoadImage` 目标人物照片 → 一次出三视图条、表情条、合成参考板。
4. 场景 / 道具 / 人像按 `图片提示词.md` 的 `PLATE` / `PAIR` 提示词分别跑 04~07。
5. 产物按 N0 契约落 `input/<项目>/{chars,scenes,props}/IMG-*.png`，再进 N5 / N9 的 `<Picture 2/3/4>`；跨图锁脸按需跑 `faceswap.py --mode board`。

⚠️ **辅助脚本缺失**：`prep_ref2.py` / `prep_ref3.py` / `n4_faceswap.py` 全库检索均无，
`ref_band_flat.png` / `ref_face_hd.png` 现阶段需手工准备（详见使用说明第三节）。
模型权重按用户口径**自行下载**，清单见使用说明第三节。
