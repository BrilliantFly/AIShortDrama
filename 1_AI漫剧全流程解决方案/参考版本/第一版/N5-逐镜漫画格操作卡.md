## 0. 定位与边界

**N5 只做一件事**：把 drama 的每一镜，画成**一镜一张**、可直接作为 H3 `<Picture 1>` 起始构图的漫画静帧 PNG。

| 本卡负责 | 不负责（交给谁） |
|---|---|
| 确认三张板就位且同源 | **生成**三张板（N4／方案 4.4） |
| 每镜出图 prompt 四段重组 | **写分镜**（N2 drama，drama 是唯一真源） |
| 挂参考图、出图、定画幅、去文字、命名 | 拆格／裁幅／去文字等补救（L3，见第 9 章判定） |
| 起始构图审片、回填 `frame_key` | 音色（N6）、六段式视频 prompt（drama 直接进 H3，不给 N5） |
| 归档每镜 prompt 与 seed | 装配 `timeline_data`（N9 `csv_to_timeline.py`）、渲染（N10–N12） |

**两条不可让渡的约束**：

- `<Picture 1>` 是**起始构图且 prompt 压不过它**——N5 画错，后面所有环节都救不回来，只能重出图。
- **一镜一张**。整页漫画／条漫／多格绘本／MP4 动态分镜都不是 N5 的产物（方案 3.6：代码渲染类 vibe 只能到「动态分镜」，不是本槽位的输入）。

| 层 | 职责 | 用什么 | 需不需要新增工具 |

#### 最终推荐与起步

- **主推组合**：`shotlist.csv`（编排）＋ **即梦「图片 4.0」／Seedream 4.0**（引擎）＋ **同一引擎**出 N4 三张板。首次在网页端手工跑 **2~3 镜**（1 对白 + 1 静默 + 1 双人）验证四段重组与挂图顺序；跑通后写 `frames_from_shotlist.py` 逐行调火山方舟 API，产物直落 `input/<项目>/frames/`。
- **全本地零费用组合**：ComfyUI 内用 Qwen-Image 2.1 故事板工作流一并出板与帧，Batch Prompts 一行一镜。此时「ComfyUI 完成三视图」与「提供三视图参考」本来就是同一件事（方案 4.4.2 判定②）。
- **不要**为了出三张板单独再搭一套独立文生图工作流：除非引擎本身就跑在 ComfyUI 里，否则板帧分属两套模型，违反 4.4.3 的同源定线，反而加剧跨镜变脸。
- **L3 适配层不需要额外工具**：B/C 能直出「单帧 + 16:9 + 无文字 + 独立文件」时，转换层 1/2/3 整体跳过（本卡第 9 章），只剩板入库汇总与音色回填，手工或同一份脚本即可。

- **成本口径**（2026-11-19 火山方舟官方价格页核准，详见手册 5.1）：`doubao-seedream-4-0` 输出 **0.20 元/张**、**输入图免费**、文生图／图生图同价、未成功输出不计费、IPM 500。每镜挂 3 张板属输入不额外收费，只有成功出的那张帧计费 → **100 镜约 20 元**，抽卡按成功张数算。网页端是「每日免费积分 + 会员订阅制」（基础 79 元/月含 725 积分等），与 API 是两套体系，批量与脚本化走 API 更划算。价格以官方下单页实时值为准。
- **本地替代**：若要把出图引擎换成 **ComfyUI**（板与帧同一个工作流、天然同源），见独立文档 `N5-ComfyUI实现卡.md`——含模型选型（许可证为硬约束）、节点清单、槽位固定化、三个语义坑、三种逐镜驱动方式与切换清单。**Step 1–8 与审片清单全部沿用，只换第 4 项的引擎实现**。

> 工具规格依据为 2026-11-18 现网核查、计费与 ComfyUI 节点为 2026-11-19 官方资料核准（手册 5.1）；本节按「组件可用」假定书写，不涉安装、版本、凭据、路径可达性。

## 2. 逐镜执行 8 步（对每一镜循环）

### Step 1 · 读该镜 drama 条目

从 `分镜.md` 的 `## SHOT-<nnn>` 取出：`### 冻结关键帧提示词`、景别／机位／运镜／起点／终点／时长、`- 视觉依据`、`- 输入参考图`（含 `顺序`）。同时查 `视觉设定.md` 的**连续性锁**（服装颜色、伤口位置、手持物、门开没开、轴线哪一侧）——`docs/character-consistency-across-shots.md:5-7` 指出这些才是跨镜穿帮主因，三视图锁不住。

**输出**：该镜的原始素材清单。**验收**：镜号与 `shotlist.csv` 行号对应，无跳号。

### Step 2 · 四段重组出图 prompt（不能原样粘贴）

`### 冻结关键帧提示词` 是写给 **H3 图生视频**的，带 `<Picture N>`／`视觉依据`／`顺序` 等 H3 语义标签，出图工具不认。按第 3 章模板重组为四段。

**验收**：重组后的 prompt 里**不出现** `<Picture N>`、`REF-`、`顺序：` 等 H3／drama 标签；`[1]` 与 `[3]` 与上一镜逐字一致。

### Step 3 · 挂参考图（槽位固定化）

按第 4 章的挂图顺序表，把三张板传入工具的参考图槽位。

> **最容易踩的坑**：drama 槽位表里 `REF-SHOT-START（顺序：1；用途：起始帧）` 是 **H3 侧的交接位**，指向的正是 N5 要产出的这张 PNG。N5 出图时**没有、也不可能有**这张输入图——跳过顺序 1，只挂 2/3/4（身份／地理／服装）。若工具要求参考图编号连续，就把工具槽位 1/2/3 **固定**分配给身份板／场景板／服装板，并全片保持同一分配，绝不按镜重排。

**验收**：同一个工具槽位永远挂同一类板；某镜不需要某板时留空槽，不把后面的图前移补位。

### Step 4 · 出图

**一镜一调、一镜一张**。文字只负责「这一个瞬间」看得见的构图、人物位置、光位、情绪；**不写动作结果**（动作留给 H3 补）。

- 禁止用「一次 9~15 张组图」代替逐镜：组图只保证风格与角色一致，画面由模型自行分发，不保证景别机位精确对应 drama；组图只用于同场景备选／定调图。
- 禁止整页、条漫、多格绘本、分格线。
- 同场景先出一张中远景**定调图**，其余镜头只取它的色调／光线／质感，**不取构图**（`short-drama-storyboard/SKILL.md:154`）。
- 双人戏强制在 prompt 里写「面对面、一左一右、绝不肩并肩」。

**输出**：该镜一张原始图。**验收**：画面里没有第二张画格、没有分格线。

### Step 5 · 定规格

16:9 横画幅、宽 ≥1344（可直接用 2560×1440 预设后下采样）；**禁止拉伸变形**；画面**无任何文字**：对白气泡、手写体字幕、拟声词、logo、水印、页码一律不要——它们会被 H3 忠实放大，且与 H3 音频层台词重复。

> 最有效的做法是在 `[4 约束]` 的 prompt 里直接禁掉，而不是出图后修。文字属「出图阶段就该筛掉」的元素。

**验收**：16:9、≥1344 宽、无变形、放大到 100% 检查无残留文字。

### Step 6 · 起始构图审片（人工，逐镜打勾）

按第 7 章清单逐项过。**一票否决项**：并肩站位、多余人物、画面带文字、非 16:9、画风与定调图不一致。不过就回 Step 2／Step 4 重出该镜，**不要试图在 H3 阶段用 prompt 纠正**。

### Step 7 · 命名入库 + 回填 CSV

命名为 `SHOT-<EP>-<镜号>.png`，落到 `input/<项目>/frames/`；把**相对 `input/` 根**的路径回填 `shotlist.csv` 的 `frame_key` 列（如 `EP001/frames/SHOT-EP001-004.png`）。

- 全片路径风格统一，且与 `--input-root` 一致。
- **N5 只回填 `frame_key`**：`ref_role_sheet`／`ref_scene_plate`／`ref_costume_pair` 由 N4／L3 填，`ref_voice` 由 N6 填，六段式由 drama 填——别在 N5 越界改这些列。

### Step 8 · 归档该镜

把「镜号 / 重组后 prompt / 参考图槽位分配 / seed / 输出文件名 / 审片结论」记一行，保证任何一镜都能回溯到它的起始帧与提示词（手册 N13）。

## 4. 挂图顺序表（槽位固定化）

| drama `顺序` | 用途 | 文件 | N5 是否作为输入 | H3 落点 |
|---|---|---|---|---|
| 1 | 起始帧 `REF-SHOT-START` | **N5 本镜产出** | **否**（产出位，非输入位） | `refs` index 1／`<Picture 1>` |
| 2 | 身份 `REF-*-SHEET` | `IMG-<角色>-SHEET.png` | **是**，全片固定 | `refs` index 2／`<Picture 2>` |
| 3 | 地理 `REF-*-PLATE` | `IMG-<场景>-PLATE.png` | **是**，同场景固定 | `refs` index 3／`<Picture 3>` |
| 4 | 服装／站位 `REF-*-PAIR` | `IMG-<...>-PAIR.png` | **是**，全片固定 | `refs` index 4／`<Picture 4>` |

三条硬规矩：**一个参考只给一个职责**（官方指南 README:83「别把三视图四张全挂，参考图等权平均会串味」）；**编号固定语义、缺图留空不重排**（README:109）；**三张板既喂 N5 出图当锚，又挂 H3 的 `refs` index 2/3/4，是同一份文件**（方案 4.4.3）。

## 5. 三种前半段取法的操作差异

> 三类取法对应的**具体工具名**已在 **1.1 工具定线**点名；本章只讲操作差异，不再重复选型。

| 步骤 | **B 分镜表工作台**（推荐） | **C 在线出图模型** | **A 一体化流水线** |
|---|---|---|---|
| 建表 | 一镜一行，直接导入 drama 分镜 | 用 `shotlist.csv` 逐行驱动 | 程序自己解析剧本 → 需强制吃 drama 分镜（模式 X） |
| 重组 prompt | 填进「提示词」列 | 一镜一调 | 程序可能自行改写 → 需中断、导出中间帧 |
| 挂板 | 填「参考卡／首帧」列 | `Image 1/2/3` | 程序内部角色资产 → **必须导出独立 PNG**（4.4） |
| 出图 | 逐镜生成，天然一镜一张 | 一镜一调 | **必须停在图生视频之前** |
| 额外转换 | 无 | 无 | 截帧拆格、裁 16:9、去手写体字幕、补音色（方案 3.6） |
| 判定 | **首选**：衔接 `shotlist.csv` 成本最低 | 可控性最强，需自己重组 prompt | 衔接最重，只在愿意换整套工程时考虑 |

> 若选代码渲染类程序（`vibe-video`／`story-to-handdrawn-video`／`motion-kit`），它产出 MP4／整页绘本，按方案 3.6 需多承担 4 条转换；**不建议作为 N5 的直接实现**。真漫剧的「角色表演」那一段由 H3 补，不是由它补。

## 7. 起始构图审片清单（逐镜打勾）

```
□ 谁左谁右符合 drama；双人面对面、一左一右，没有肩并肩
□ 无多余人物；无血迹绷带、现代物品等连续性锁禁止项
□ 无任何文字：气泡／字幕／拟声词／logo／水印／页码／分格线
□ 16:9 横画幅、宽 ≥1344、无拉伸变形
□ 画风与定调图一致；同场景色温／光线／质感一致
□ 只画了一个瞬间，没有把动作结果画进去
□ 镜号与文件名、CSV 行、drama SHOT 号三者一致
□ 三张板仍是全片同一份，没有被本镜临时替换
```

**一票否决 → 回 Step 2／Step 4 重出该镜。** `<Picture 1>` 的构图 prompt 压不过它，后期修不了。

## 8. 常见坑与回退

| 现象 | 根因 | 回退到 |
|---|---|---|
| 构图错、双人并肩、多余人物、画面带文字 | 出图阶段没审住 | **Step 4／Step 6 重出该镜格**（不是改 H3 prompt） |
| 跨镜变脸 | 三张板被逐镜换、或只留在程序图层里没导出 | N4／4.4，重新导出独立 PNG 并全片固定 |
| 画风每镜跳 | `[3 画风句]` 被逐镜重写；或板与帧不同源 | Step 1 锁定项 1/2；方案 4.4.3 |
| 起始帧变成标准站姿定妆照 | 把三视图 SHEET 挂进了 `<Picture 1>` | Step 3 挂图顺序；三视图只进 `<Picture 2>` |
| 槽位对调（SHOT-023 型事故） | 用「顺序」当身份、按镜重排 | Step 3 槽位固定化，缺图留空 |
| 一页多格被当成一格放大 | 用了整页／条漫／组图 | Step 4 改逐镜单帧；整页 storyboard sheet 不进生产链 |
| 文字与台词重复、被放大 | `[4 约束]` 没禁文字 | Step 5；已有页面交 L3 第 3 条处理 |
| 参考图与提示词打架（写实／漫画摇摆） | N7/N9 的 negative 还留着「卡通／动画感」 | 后半段画风同步：删负向禁项、正向改漫画向 |
| 对白镜「有声音听不懂」 | 用了 4step 预览档 | H3 阶段：25step + 参考音色 + 段尾 `Audio: reference`（与 N5 无关，别回 N5） |

## 9. 与 L3 适配层的分工（最容易含糊）

转换层 5 条里，**N5 在出图时就能做掉前 3 条**；L3 只做补救与汇总。

| 转换层条目 | N5 已做 | 交给 L3 的条件 |
|---|---|---|
| 1 拆格 | Step 4 直接出一镜一张单帧 | 程序只吐整页／条漫／MP4 时，才由 L3 拆格 |
| 2 定画幅 | Step 5 直接 16:9 ≥1344 | 程序固定竖版／3:4 时，才由 L3 居中裁切 |
| 3 去文字 | Step 5 在 `[4 约束]` 里禁掉 | 已有页面残留文字时，才由 L3 后期修 |
| 4 板导出 | Step 3 挂的板本就是独立 PNG | **仍需 L3 汇总**到 `chars/scenes/props/` 并回填 `ref_*` 三列 |
| 5 补音色 | 不属 N5 | **N6** 出 wav，**L3** 回填 `ref_voice` |

**判定规则**：若出图工具能直出「单帧模式 + 16:9 + 无文字 + 独立文件」，L3 的 1/2/3 可整体跳过，只保留 4（板入库）与 5（音色）。这也是推荐取法 B/C 的原因——它们把转换层前置到出图参数里，比 A 类事后补救省事。

## 10. 最小验证（先跑 2~3 镜，别直接上量）

1. 选 **1 个对白镜 + 1 个静默镜 + 1 个双人镜**（示例：S004 / S006 + 任一 DUO 镜）。
2. 按本卡 Step 1–8 走完整循环，锁住三张板与画风句。
3. 回填 `frame_key` → `python csv_to_timeline.py --check-only` → 01 快出预览审构图。
4. **出口标准**：H3 忠实保留 `<Picture 1>` 的站位与构图、无文字、无变形、角色不漂、双人面对面。

任何一条没达标，先回 N5 修出图参数；转换层没生效就批量跑，只会批量放大废片（方案阶段 1）。
