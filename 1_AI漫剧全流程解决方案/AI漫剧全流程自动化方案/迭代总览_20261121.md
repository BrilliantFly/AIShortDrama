## 五、完整链路（新项目从剧本到成片）

```bash
PY="D:/ComfyUI-aki-v3.2/python/python.exe"

# N3 上游：视频提示词.md → 三件套草稿（人工补身份块/冻结帧/PLAN 映射/场景圣经定稿）
python prepare_project.py --motion-md <视频提示词.md> --project <项目> --ep <集号> \
  --out-dir out/prepared --plan-map 'PLAN-SU-SHEET=<路径>;...'

# N4 换脸（可选，先出板→换脸）：板换脸用 --mode board，逐帧用 --mode frames
python faceswap.py --mode board --jobs-config board_jobs.json
python faceswap.py --mode frames --frames-dir <input>/<项目>/frames --plan '011:male,female;006:skip' ...

# N5 出帧（本机单阶段）：填好 n5_inputs → dry-run → 连 ComfyUI
python frames_from_shotlist_comfy.py --inputs out/prepared/n5_inputs.json --dry-run
python frames_from_shotlist_comfy.py --inputs out/prepared/n5_inputs.json \
  --workflow-template 工作流底座/n5_zimage_single.json --csv out/prepared/shotlist.csv

# N9 装配：单镜 workflow（实跑 A 方案）+ 场景锁
python csv_to_timeline.py --csv out/prepared/shotlist.csv --per-shot --out out/shots \
  --scene-bible out/prepared/scene_bible.txt

# N12 渲染逐镜提交（断点续跑）
python render_submit.py --shots-dir out/shots --all --csv out/prepared/shotlist.csv \
  --out-root <交付根>

# N14→N15→N16 后期（先精修，再拼接，最后质检；详见 后期与质检/README.md）
$PY 后期与质检/qc_gate.py --videos <成片目录> --list <清单.csv> --report qc.json
$PY 后期与质检/audio_tighten.py --videos <成片目录> --out <精修目录> --all --talk-shots <对白镜>
$PY 后期与质检/concat_xfade.py --videos <成片目录> --audio-fix --fixed-dir <精修目录> --out 全片.mp4
```

## 五之二、两版产物分叉（2026-11-21 二次定线）

上面 N14→N15→N16 产出的是 **成片版**（按 CSV 全段叠化的单一全片）。同批精修片段另出一版 **片段版**，专供 N17：

```bash
python tools/prepare_two_versions.py \   # 在 6_剪辑 目录下执行（先 activate.bat）
  --out-root <交付根> --csv out/prepared/shotlist.csv \
  --project-root <N17 工程根> --ep EP001 --fixed-dir <精修目录> --verify
```

产物：`剧集/EP001/制作成果/videos/MOTION-EP001-*.mp4` + `剪辑单.md` 草稿 + `视频提示词.md` 骨架 + `成片版命令.md` + `两版产物说明.md`。`--verify` 会直接跑 `edit_tool.py check`（合成素材实测 `findings: []`）。两版并列，N17 从片段而非成片出发。
