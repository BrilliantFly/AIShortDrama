## 4. 命令速查

```bash
# 体检（不写文件）
python csv_to_timeline.py --check-only

# 双份装配 + 一致性校验
python csv_to_timeline.py --csv shotlist_vibe_template.csv --dual ^
  --out out/H3-vibe-EP001-G01-dual.json --seed 42
python csv_to_timeline.py --compare out/H3-vibe-EP001-G01-dual_preview.json ^
  out/H3-vibe-EP001-G01-dual_final.json

# 出帧：导出材料模板 → 填 drama 冻结关键帧 → dry-run 验槽位 → 连 ComfyUI
python frames_from_shotlist_comfy.py --emit-inputs-template out/n5_inputs.template.json
python frames_from_shotlist_comfy.py --dry-run --inputs out/n5_inputs.example.json
python frames_from_shotlist_comfy.py --emit-workflows out/wf --inputs out/n5_inputs.example.json
python frames_from_shotlist_comfy.py --server 127.0.0.1:8188 ^
  --workflow-template n5_comfy_template.json --inputs out/n5_inputs.example.json ^
  --input-root "<ComfyUI input>" --seed 42
```

> **材料边界**：drama 的冻结关键帧提示词**不在 CSV 里**。出帧脚本必须先用 `--emit-inputs-template` 导出材料、填入 `identity_block` 与 `frozen_keyframe`，再用 `--inputs` 指回；它不会从 `detailed_description`（动作结果）臆造起始帧。
