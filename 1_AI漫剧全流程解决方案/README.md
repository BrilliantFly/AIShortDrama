## 4. 审核前稿是怎么来的（可核查）

`参考版本/第一版/`（原第一版）**不是重新撰写的**，而是从本次对话的完整操作记录里**重放**每一次文件写入与编辑，回放到「审核全流程」之后、「四项决定」之前的状态：

- 自检方法：把**全部**写入/编辑重放到最后，与磁盘上的当前文件逐字比对 → **10 个交付物 9 个逐字一致**，CSV 仅差一个 UTF-8 BOM（已补）。
- 还原后的原第一版装配脚本**实跑通过**：`--check-only` 0 错误，装配出 2 段 / 248 帧 / 10.333s 的示例副本，即 `参考版本/第一版/out/H3-vibe-EP001-G01.json`。

因此原第一版与定稿之间的 diff 就是这轮修订的真实 diff，可以直接用文件对比工具查看。`参考版本/第二版/`（原第三版）为机械复制，无独立 diff。

  out/H3-vibe-EP001-G01-dual_final.json
