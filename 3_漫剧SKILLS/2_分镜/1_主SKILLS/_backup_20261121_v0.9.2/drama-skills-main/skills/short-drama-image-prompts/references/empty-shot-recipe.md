# 空镜与氛围过场镜配方

> 空镜 = 画面内无说话人物、无口型压力的过场图/镜：场景建立镜（黑木崖全景）、
> 情绪过场（风吹动荷塘）、转场垫镜（雨打窗棂）。这类镜不受站位/镜型/台词约束，
> **美学密度可以放开**——网络爆款提示词（巨幅荷叶、丁达尔光、人物只留背影）多半
> 属于这一类。但"放开"不等于写空词，本配方给出三层写法与边界。

## 什么时候用

- 分镜里出现无台词、无表演的过场镜（来源字段无对白，或明确标 `空镜`）；
- 场景板需要一张"剧情时刻"的代表图（区别于影棚式均匀光照的地点板）；
- 转场需要一张不承载人物叙事信息的垫镜。

## 与其他配方的关系

- **地理锚点从[地点板](location-plate.md)取**：空镜是地点板的一个"时刻"，不是新场景——
  场景固定锚点、尺度、材质逐字继承，只换光态与天气；
- 光态变化受[光的设计](../../short-drama-storyboard/references/lighting-craft.md)约束：
  同一连续场景不换光源关系，空镜的光必须与相邻叙事镜自洽；
- 氛围词按[通用配方·氛围与大气层](common-recipe.md)落可见结果，堆词即空词。

## 三层写法

按顺序写，每层一段，一层不达标先修这层：

1. **器材锚**：机位与取景（俯拍/仰拍/水面平视）、焦段感受（广角纳巨物/长焦压层叠）、
   景深。空镜没有"谁的肩在前景"问题，机位语言可以写得更放开；
2. **氛围层**：最多两三个与本镜情绪相关的氛围词，全部落成可见结果
   （光束×遮挡物、逆光×亮尘、巨物×尺度参照、雾×空气透视）；
   **尺度参照物是巨物感的硬要求**——画面里必须有一个可比对的对象（人、船、门框），
   或干脆用背影人物当参照（此时人物不是叙事主体，只报"背影人物，不入账"）；
3. **负面基线**：按[外部工具资产直出块](asset-export-blocks.md)的基线 +
   空镜增补（如 `cluttered`）；写实风格补 `plastic texture`。

## 可复制骨架

```markdown
{机位与取景}，{焦段感受}，{景深}。{场景锚点，取自地点板：主要物象与材质}。
{氛围词 1}：{可见结果}。{氛围词 2}：{可见结果}。{尺度参照物与巨物对比}。
{光向与受光结果}，{色调}。动态元素：{风/水波/光斑等小幅运动清单}（进视频时用）。
Negative: {基线 + 空镜增补}
```

## 画外冲突承载镜（以景写人）

普通空镜是过场（转场、定调）；**承载镜**是叙事——冲突在画外继续，画面只拍环境的反应。
经典用法（卧虎藏龙"只拍竹浪不见人"）：打斗白热时不直拍人，切一片剧烈晃动的竹林/
摇曳的火把群/被掌风推开的雾，观众自己在想象里完成那一场打。写法与普通空镜的差异：

- 动态幅度**刻意加大**：竹浪起伏、火把齐晃、水花炸开——与「红线」的小幅运动条款相反，
  承载镜的"动静"就是它的叙事内容；但仍不出现人物
- 环境物必须是本场「场景站位」登记过的锚点，反应程度与画外动作量级对齐（轻功=竹梢
  弯沉，重掌=整片竹林翻涌），不许凭空多出可破坏物
- 承载镜前后必须各有一次人物镜锚定空间（观众知道"画外是谁在打"），不连用两张承载镜；
- 恐怖/悬疑用法同理：**画外威胁不写威胁本体**，只写环境对它的反应（门缝缓缓变宽、
  灯忽明忽暗、猫弓背盯向画外同一处）——反应物的视线方向必须与站位块轴线一致，
  全画外威胁可以连续使用（这正是"以不动衬惊吓"），但每镜的反应物状态要有递进；
- 用途按过场处理，但分镜侧建议按 [武打镜容量](../../short-drama-storyboard/references/fight-shot-budget.md)
  的「环境破坏」路登记——承载镜就是环境破坏路的画面载体

## 空镜进视频提示词

- 动态幅度写**小幅运动**：水面涟漪、叶隙光斑缓移、雾气缓慢流动——空镜的大幅运动
  （狂风拔叶）会让后续叙事镜的光态接不上；
- 无人物即无口型/音轨负担，`overall_soundscape` 写环境声即可；
- 空镜与其后第一个叙事镜共用同一场景锚点与光向，交接核对走分镜既有流程。

## 红线

- 空镜**不得承载叙事人物信息**：背影人物只作尺度参照，不写表情、动作剧情——
  需要表演就回叙事镜体系（站位/镜型/口型）；
- 空镜的地理与光态与相邻镜冲突时，回地点板/光设计修订，不在空镜里另起一套；
- 排除项不否定必需项（如要求水面倒影又排除一切反光）；
- 不把 `--s`/`--c` 等单平台参数写进正文。
