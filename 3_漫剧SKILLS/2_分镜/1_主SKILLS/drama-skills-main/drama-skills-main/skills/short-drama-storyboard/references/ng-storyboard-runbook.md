# 从分镜到成片：NG 导演台运行手册

把一场戏从《分镜.md》送进 ComfyUI 的 **H3 NG 导演台（06-故事板-双角色）** 并出片，照本文一步步做即可。

本文只管**操作顺序与判定标准**；坐标怎么标定、字段怎么映射、哪些情形摆不出来，见  
[导出到 NG 故事板](ng-storyboard-export.md)，两文不重复。站位与调度怎么写，见  
[调度手册](blocking-playbooks.md)。换用没有故事板节点的模板（通用 01/02/03 的 r2v 线）时，
定位改由参考图与提示词承担，逐条问题见 [无坐标定位问题点](maxdirector-blocking-faq.md)。

## 一、三件事各管一段

| 环节           | 谁负责                        | 顶替不了的后果       |
| ------------ | -------------------------- | ------------- |
| 人物**摆在哪、多大** | `storyboard_to_ng.py`（坐标）  | 手拖，且前后镜无法机械比对 |
| 画面里**是谁**    | 角色卡（卡名 = `@代称`）            | 位置全对，人脸是别人    |
| 画面**像不像电影**  | Redraw all panels（Qwen 重绘） | 出来是抠图拼贴，不是成片  |

转换器不碰后两件。三件缺任何一件，症状各不相同——排查时先认出是哪一件，见 §七。

## 二、开工前准备

| 素材              | 最低要求                                               | 从哪来                       |
| --------------- | -------------------------------------------------- | ------------------------- |
| `剧集/<EP>/分镜.md` | 已过 `storyboard_lint.py`；场首有「场景站位」，每镜有「景别/机位」「视觉依据」 | 本 skill 的产出               |
| 《视觉设定.md》       | 人物条目里有「画面代称」                                       | 同目录同名会自动读；没有就用 `--cast` 补 |
| 人物抠图            | 透明底**全身**立绘，一人一张，人物完整不裁脚                           | 美术或换装生成                   |
| 角色卡             | 一张身份板（正面全身 + 面部），双角色要两张，**卡名定好**                   | 自己的资产库                    |

**卡名规范**：与《视觉设定.md》的「画面代称」逐字一致，建议拼音无空格（`LinghuChong`、  
`DongfangBubai`）。脚本把分镜里的人名换成 `@代称` 写进提示词；卡名不一致，`@代称` 就绑不到  
`<Subject N>`，画出来是模板里那张示例脸——这是「身份混淆」最常见的真实原因，不是图层排错了。

**抠图不合格的三种表现**：脚被裁（半身图摆全景会露出硬切口）、背景没抠净（重绘时被当成人）、  
同一人物多视图混放在一张图里又没标归属（重绘会随机挑一个角度）。

## 三、跑转换（每集一次）

命令在仓库根执行（路径同理见 `scripts/storyboard_to_ng.py` 的 `--help`）：

```bash
python skills/short-drama-storyboard/scripts/storyboard_to_ng.py \
  剧集/EP001/分镜.md \
  --out 剧集/EP001/制作成果/EP001.storyboard.json \
  --workflow "F:/skills/工作流/09-H3导演台-NG版/H3-NG导演台-06-故事板-双角色.json" \
  --out-workflow 剧集/EP001/制作成果/EP001.workflow.json \
  --figure "陈屿=assets/chenyu-cut.webp" \
  --figure "林知夏=assets/linzhixia-cut.webp" \
  --bg "旧书店门廊（雨夜）=assets/porch.jpg"
```

| 参数                 | 不给会怎样                                            |
| ------------------ | ------------------------------------------------ |
| `--out`            | 必填，写 `h3-storyboard` 文档                          |
| `--workflow`       | 不注入模板，只出一份 JSON，得自己粘进节点                          |
| `--out-workflow`   | 默认与 `--out` 同名加 `.workflow.json`                 |
| `--figure "名字=文件"` | 用 `h3-example-*.webp` 占位，构图能看、人脸是示例人物            |
| `--bg "地点名=文件"`    | 不给则用 `h3-example-hall.jpg` 占位；只给文件不给地点名，则全场共用那一张 |
| `--cast "中文名=代称"`  | 没有《视觉设定.md》时唯一的 `@代称` 来源                         |
| `--max-panels`     | 默认 9（NGStoryboard 上限），超出只写前 9 个                  |
| `--scene`          | 按场次 ID 筛选（逗号分隔，如 `SC01,SC02`），匹配分镜「来源」字段 |
| `--fps`            | 只影响缺 `时长` 时的折算，默认 24                             |

**先试跑再落盘**：想只看报告不动产物，把 `--out` 指到临时路径（`/tmp/try.json`）跑一遍；  
要喂给别的脚本就加 `--json-report`，报告以 JSON 打印。

退出码：`0` 成功（可能带提示）／`1` 没解析到 `## SHOT-…` 块／`2` 路径或格式错误。

成功时的逐镜清单长这样，**逐行核**：

```
写出 EP001.storyboard.json（6 个面板 / 3 条素材）
  p1  4.25s 雨把整条街压成蓝       （无人物图层）
  p2  2.83s 雨水顺着他下巴淌       Chenyu x=0.30 y=0.85 s=0.80
  p3  2.13s 她回头                 Linzhixia x=0.70 y=0.85 s=0.80
  p4  4.25s 他奔上台阶             Chenyu x=0.30 y=0.66 s=0.12 | Linzhixia x=0.70 y=0.66 s=0.12
  p5  4.25s 我喜欢你               Chenyu x=0.30 y=0.70 s=0.42 | Linzhixia x=0.70 y=0.70 s=0.42
  p6  2.83s 雨还在下               Linzhixia x=0.70 y=0.66 s=0.12 | Chenyu x=0.30 y=0.66 s=0.12
写出 EP001.workflow.json
```

看三件事：**panel 数 = 镜数**、**同一人物跨镜 x 是否稳定**（p2 与 p5 都是 0.30 才对）、  
**同一景别档 scale 是否一致**（全景 0.12／中景 0.42／近景 0.80）。有一处不对，回分镜补字段重跑，  
不要在面板里硬拖——拖了下一版分镜又要重来。

## 四、两份产物

| 文件                  | 内容                                           | 什么时候用                          |
| ------------------- | -------------------------------------------- | ------------------------------ |
| `*.storyboard.json` | 干净的 `h3-storyboard` 文档（panels + library）     | 粘进已有工作流的 H3 Storyboard 节点；存档比对 |
| `*.workflow.json`   | 上述文档 + Director 的 shots 与 Duration 已写好的完整工作流 | **日常首选**，打开即用                  |

注入版做的是三件事：H3 Storyboard 节点的 `widgets_values[0]` 换成本场故事板；NGH3Director 的  
`shots` 按 panel 切成 `sb-p1…`，时间轴首尾相接；Duration 写总时长。`media` 故意留空，理由见 §六。

## 五、ComfyUI 里的六步

| # | 动作                       | 成功标志                                                          |
| - | ------------------------ | ------------------------------------------------------------- |
| 0 | 打开 `EP001.workflow.json` | 画布上六个 panel 各有背景 + 人物图层，比例位置已就位                               |
| 1 | 换角色卡                     | 两张卡换成自己的身份板；卡名 = `@代称`；三栏设 `character` / `reference` / `high` |
| 2 | 校 panel                  | 逐 panel 对报告清单：人数、左右、景别档；与分镜不一致的当场改图层或回改分镜                     |
| 3 | **Redraw all panels**    | 拼贴变成照片质感；人物脸与角色卡一致；背景接缝不突兀                                    |
| 4 | **Use in Director**      | sheet 被登记为可用媒体，Director 侧能引用到这张图                              |
| 5 | **Send to Director**     | panel 变成 shot，`media` 自动挂上刚注册的图；shot 数与 panel 数相同             |
| 6 | **Generate**             | 按 ~10s 切段渲染再拼成一条；保存到 `H3/storyboard`                          |

第 2 步是唯一值得慢下来的地方。图层按列表顺序叠加、靠后的盖住靠前的，脚本按「视觉依据」里人物  
出现的顺序添加，**不按前后景深度排序**：需要谁挡住谁，就在面板里把该层挪到后面（过肩镜的前景肩  
永远压在最上层）。排错遮挡关系会让该被挡住的人挡在前面。

第 3 步依赖本地有 Qwen Image 2.1；模型缺失会在重绘时直接报错，与故事板无关。

第 6 步不用手填时长：20.54s 会分成两三段渲染再拼，属正常。分段的边界由 Director 内部按 ~10s  
切，不是按 panel 边界切——所以跨段的 panel 首尾帧要能接住，见 [镜间交接帧](shot-handoff.md)。

## 六、按钮顺序为什么不能反

`panel 内容 →（Redraw）→ sheet 图 →（Use in Director）→ 媒体卡 →（Send to Director）→ shot.media`

四步是一条链，每一步吃上一步的产物。**先 Send 后 Redraw**，`shot.media` 挂的是重绘前的拼贴图，  
Generate 拿到的是抠图剪纸，人物边缘和光影都不对；**跳过 Use in Director**，media 为空，等于退化成  
纯文生视频，人物身份没有任何约束。

反过来也有坑：Redraw 之后又去改 panel 图层，必须**再 Redraw 一次并重新 Send**，否则 Director 里  
还是上一版构图。

## 七、排查表

| 症状                  | 真正的原因                      | 处理                              |
| ------------------- | -------------------------- | ------------------------------- |
| 某 panel 没有人物，只有背景   | 物证特写／空镜／人物只出现在画外           | 正常；确实要人就补 `- 图层：名字 x=… scale=…` |
| 人物左右与分镜相反           | 逐镜文本没写清左右，落到了等距分布或场景站位兜底   | 报告里找「读不出 … 在画面哪侧」，补分镜或硬指定 `x=`  |
| 大小与景别明显不符           | 认不出景别，按中景摆放                | 报告里找「认不出景别」，补「景别/机位」            |
| 人脸不是自己的角色           | 角色卡没换；或卡名与 `@代称` 不逐字相同     | 逐字核对卡名，改卡不改分镜                   |
| 出来是拼贴剪纸感            | 没 Redraw 就 Send            | 回 §五 第 3 步                      |
| 只有前 9 个镜头           | 超出 NGStoryboard 上限被截断      | 按场次拆成两张故事板，各自跑一次                |
| 总时长比分镜短             | 有镜缺 `时长`，按 5s 兜底           | 补 `时长` 重跑                       |
| 特写镜里是全身小人           | 全身抠图缩不出脸                   | 换面部图或在面板里单独放大                   |
| 过肩镜前景肩太实、太大         | 已知失真：图层做不出贴边虚化             | 手调该层 `scale` 并贴边                |
| Director 里 shot 数不对 | 模板里没有 NGH3Director，只替换了故事板 | 看报告末条，换用 06 模板                  |

## 八、出片前验收

- [ ] 报告里没有「认不出景别」「读不出 … 哪侧」「缺 `时长`」三类提示
- [ ] 占位素材（`h3-example-*`）已全部换成真图
- [ ] 每个 `@代称` 都能在画布上找到同名角色卡
- [ ] panel 数 = 分镜镜数（或已按场拆分，且拆分处首尾能接）
- [ ] 同一人物跨镜 x 稳定，除非剧情要求换位
- [ ] 面板总时长 = 分镜总时长
- [ ] Redraw 之后没有回头改过图层（改过就重绘重送）
- [ ] 跨段渲染的接缝处，上一镜末帧与下一镜首帧是同一个状态

## 九、边界

- **只搬已经写明的**：分镜没写左右、没写景别，脚本不猜构图，只报警；读不出来先补分镜。
- **9 panel 上限**：一集 20 多镜必然要按场拆，这是模板限制不是脚本限制。拆板按「一场一组  
  panel」切，产物按 `EP001-S01.storyboard.json` / `EP001-S01.workflow.json` 命名，回头改某一  
  场只重跑那一条命令。  
  **已支持按场/镜号筛选**：`--scene SC01`（按分镜「来源」的场次 ID，逗号分隔可给多个）、
  `--shots 001-005`（镜号尾段或区间）——不再需要手工裁临时 md；两个都给时取交集。
- **不适用**：单场改一两镜（直接拖更快）、纯文生视频（01 模板）、每镜钉首帧（04 模板）——它们  
  不经过故事板这一层。
- **表达不了的**：半透纱幔遮挡层、精确垂直高度、跨镜动作连续性。纱幔手调或重绘时写进提示词，
  后两项按 [镜间交接帧](shot-handoff.md) 处理。过肩前景肩已自动化：OTS 镜读出「越过X的肩 /
  X的肩背」或「人物「X」（…虚化肩背…）」时，前景自动放大贴边置顶层——要手调就写
  `- 图层：代称 scale=… x=…` 覆盖。
