# 声音字段写法：三层分流与五槽位（M1/M3）

> 第五轮手册编译验证的产物。背景：lint 此前对声音内容零检查——同一场戏「照抄手册」与
> 「三层分开写」两稿得到完全相同的 PASS，而照抄稿里 7/16 镜只有配乐指令，直接搬到 H3
> 会让 `overall_soundscape` 写空。本文给出可复制的写法；`storyboard_lint.py` 现已带两条
> 对应 WARN，被拦的稿按本文改写即可。

## 一、三层分流表（拿到任何声音素材先做这一步）

把素材里的每条声音指令先归类，再决定去向：

| 层 | 例子 | 去向 |
|---|---|---|
| **画内声**（画面里的人/物发出） | 竹竿受压干裂声、她一次吸气、外套摩擦 | `声音` 字段主体：材质 + 单次/连续 + 接触面 |
| **环境底**（空间持续声） | 风穿过竹梢、远处车流、雨幕 | `声音` 字段：距离/方位/延续（「自画面深处滚向前景」「承接上一镜延续」） |
| **配乐**（观众听觉，画面外） | 弦乐渐强、鼓点、乐句上扬 | **不进** `声音` 字段——写进制作备注或后期；生成端写 `non_diegetic_music: N/A` |

判据一句话：**这个声音是画面里的世界发出的吗？** 是 → 画内或环境；不是（情绪性的音乐）→ 后期。

## 二、`声音` 字段五槽位

真实生产稿 28 段实测：`non_diegetic_music: N/A` 28/28、93% 三段分号并列。稳定的结构是：

```
画内声（人声质地；道具音=材质+接触面+单次/连续） ; 环境底（距离|方位|延续） ; 无对白/台词
```

- **人声质地**：气声重、句尾发颤、压着说——写在台词外，不进台词本体
- **道具音**：材质（干裂/金属/布料）+ 接触面（贴镜头/撞上邻竿）+ 单次或连续
- **环境底**：必须有**空间词**（自画面深处/由左/贴地一圈闷响/压低半拍）——没空间词的
  环境底混出来是平的；跨镜延续写「承接 SHOT-xxx 的 xx 声延续」
- **配乐层**：一律 `无配乐` 或 `non_diegetic_music: N/A`，需要配乐是后期的事

### 有台词的镜（最容易写坏的形态）

坏例（既有稿的真实形态，lint M2-② 现在会拦）：

```
- 声音：东方不败道:「四个人,一起上吧。」
```

台词之外一个字没有——出片时 soundscape 只能写成台词本身，混响、底噪、空间感全丢，
效果是配音棚里贴的一句话。改写：

```
- 声音：画内——东方不败道:「四个人,一起上吧。」（12 字，哭腔拖慢语速，估 3.0–3.5 秒）；
  抽泣两下压在句前，贴镜头、无余响；环境底——殿内烛火噼啪一次，远处更漏声延续承接上一镜；无配乐。
```

三层各司其职：台词归台词（lint 数它）、估时归括号（人读它）、环境底归环境底（H3 读它）。

## 三、只有配乐的素材怎么办（M3 转写实表）

手册竹海段 7 镜只有配乐指令（02/06/07/09/11/14/15）。**声音内容全部能从画面读出来**，
这是转写不是创作。逐镜补写方案：

| 镜 | 手册原文 | 画面内容 | 补写方向 |
|---|---|---|---|
| 02 | 音乐渐强 | 竹林摇镜头，竹竿排空而过 | 竹竿擦碰的连续轻响由远及近；风声为底 |
| 06 | 弦乐陡然拔高 | 李慕白跃起点竹梢 | 蹬竹一声闷响（木质、单次），竹梢回弹的吱声 |
| 07 | 弦乐持续 | 他在竹梢上起伏 | 竹梢受重的连续吱声随起伏变调；风声压低 |
| 09 | 音乐收住 | 玉娇菊落竹面稳住 | 落竹一声闷响 + 竹面回弹两下；随即静 |
| 11 | 弦乐余音 | 两人对峙喘息 | 两人呼吸声（一粗一细）；竹叶沙沙底噪 |
| 14 | 音乐渐弱 | 玉俯冲下滑 | 衣料破空声贴镜头，竹叶被气流带起的连响 |
| 15 | 余音袅袅 | 竹海空镜 | 只留环境底：风声由强渐息，一两声鸟鸣 |

填法照第二节五槽位；每条都带材质、单次/连续和空间词。

## 四、机器门禁（已落地）

`storyboard_lint.py` 两条 WARN（词表与第五轮探针一致，41 镜 0 误报）：

- **M2-①**：剥掉否定声明后只含配乐词、无画内/环境声词 → 补三层
- **M2-②**：有台词但除台词与估时外无任何环境/画内声词 → 补环境底

对照实验基准：`验证-声音层/` 的 A 稿（照抄手册）被拦、B 稿（三层分开）干净。

## 五、边界

- 手册/拉片素材的音乐常常**就是**那段戏的剪辑点（「音乐顿住」标出切点位置）——转写时
  把它的节奏功能记进「目的」或转场字段，不是丢掉音乐信息，只是换个地方放
- `cicadas continue` 这类跨段延续写法来自真实生产稿，是否真被模型读到未逐条验证；
  写总比不写好，但别指望它是硬约束
- 台词估时的完整规则仍以 SKILL.md「对白估时」与 voicetrack-renderability.md 为准，本文只管
  声音内容的写法
