# 导出到 NG 故事板（H3 导演台 06 模板）

把《分镜.md》里已经写好的站位与景别，换算成 ComfyUI **H3 Storyboard**（`NGStoryboard`，
工作流 `09-H3导演台-NG版/H3-NG导演台-06-故事板-双角色.json`）的 `h3-storyboard` 文档：
每个镜头一个 panel，panel 里是背景层 + 人物图层，每层带 `x / y / scale`。

**为什么值得做**：分镜里的站位是散文（「林知夏在画面右」），产线上要人照着文字去拖图层，
于是「站位不对」只能靠眼睛发现。换成坐标以后，左右是 0.30 / 0.70，景别是 0.17 / 0.42 / 0.60，
同一场戏里前后镜是否一致可以逐行比对。

**它不是新规范**：脚本只搬运分镜里已经写明的事；读不出来的进报告，不静默编造。

## 一、命令

```bash
python scripts/storyboard_to_ng.py 分镜.md --out 故事板.json

# 有《视觉设定.md》时自动取「画面代称」当 @名字、取画幅；没有就手动给
python scripts/storyboard_to_ng.py 分镜.md --out 故事板.json \
    --cast "令狐冲=LinghuChong" --cast "东方不败=DongfangBubai"

# 换掉占位素材
python scripts/storyboard_to_ng.py 分镜.md --out 故事板.json \
    --bg "旧书店门廊（雨夜）=porch.jpg" \
    --figure "林知夏=linzhixia-cut.webp" --figure "陈屿=chenyu-cut.webp"

# 直接注入 06 模板，另存一份能打开的工作流
python scripts/storyboard_to_ng.py 分镜.md --out 故事板.json \
    --workflow "09-H3导演台-NG版/H3-NG导演台-06-故事板-双角色.json" \
    --out-workflow 我的故事板.json
```

| 选项 | 作用 |
|---|---|
| `--visual` | 指定《视觉设定.md》；不给则读分镜同目录下同名文件 |
| `--cast 中文名=代称` | 没有视觉设定时的 @名字来源 |
| `--bg "地点名=文件"` | 按「视觉依据」里的地点名分别配背景；只给文件则全场共用 |
| `--figure "名字=文件"` | 人物抠图（透明底全身）；不给则用模板示例素材占位并在报告里点名 |
| `--max-panels` | 默认 9（NGStoryboard 上限）；超过就只写前 N 个并提示按场次拆 |
| `--workflow` | 注入模板：改写 NGStoryboard 的面板、Director 的 shots 与 Duration |
| `--fps` | 没有 `时长` 字段时按 `export_frames ÷ fps` 折算，默认 24 |

退出码：0 成功（可能有提示）／1 没解析到镜头块／2 路径错误。

## 二、字段映射

| 分镜字段 | 去向 | 规则 |
|---|---|---|
| `## SHOT-…` 标题 | panel `title` | 取「·」后的标题，截 24 字 |
| `时长`（缺则 `export_frames÷24`） | panel `seconds` | panel 首尾相接，累加成项目总时长 |
| `目的`（缺则 `唯一动作`、正文） | panel `caption` | 截 160 字，只上海报不上提示词 |
| `冻结关键帧` 正文 | panel `shot` | 压成一行；人名换成 `@代称`；正文没点名时前置 `In frame: @A at frame left.` |
| `视觉依据` · 地点「X」 | 背景层 `name` + 素材库 | 有 `--bg` 映射就用对应文件 |
| `视觉依据` · 人物「X」 | 人物图层 | 去掉「画外：人物「X」」——画外的人不摆图层 |
| `景别/机位`（缺则读正文） | 图层 `scale` / `y` | 见下表 |
| `屏幕方向`（场景站位） | 无逐镜线索时的 `x` | 只作兜底，逐镜文本优先 |
| `- 图层：名字 x=… scale=…` | 覆盖任意图层字段 | 垂直高度、OTS 前景这类自动推不准的，用这一行硬指定 |

## 三、坐标标定

`scale` 是人物图层相对 panel 高度的占比，`y` 是图层中心。标定值取自 06 模板的实测面板
（全景 0.17 / y 0.64、中景 0.42 / y 0.70、中近景 0.60 / y 0.80 三档完全吻合），
其余档按同一公式 `y = head_y + scale / 2` 外推：

| 景别 | scale | head_y | y | 识别词（中/英） |
|---|---|---|---|---|
| 大景 | 0.12 | 0.60 | 0.66 | 大景/远景/establishing/extreme wide |
| 全景 | 0.17 | 0.555 | 0.64 | 全景/wide shot/full shot |
| 中全景 | 0.30 | 0.50 | 0.65 | 中全景/medium wide/cowboy |
| 中景 | 0.42 | 0.49 | 0.70 | 中景/medium shot/two-shot |
| 中近景 | 0.60 | 0.50 | 0.80 | 中近景/medium close/mcu |
| 近景 | 0.80 | 0.45 | 0.85 | 近景/close-up/close on |
| 特写 | — | — | — | 特写/extreme close/macro |

`x`：左 0.30／中 0.50／右 0.70；三人以上无左右线索时按 0.30–0.70 等距分布。

**左右线索的判读顺序**（脚本内部）：

1. `- 图层：` 行里的 `x=`（最高优先）
2. 逐镜文本：`景别/机位` → `起点` → `终点` → `唯一动作` → 关键帧正文
   - 强线索：`left/right side|third|half|edge`、`left/right foreground`、`center frame`、`画左/画右`
   - 弱线索：`at lower left` 这类只带介词的说法；强线索没分到人时才用
   - 归属规则：英文习惯是「先说人再说位置」，所以同一小句里**先出现的那个人**优先，
     前面没人时才看后面提到的人（`his shoulder fills the left foreground` 归他，不归后面的她）
3. 场景站位「屏幕方向」——只作兜底，因为它是轴线级规则，正反打里会反过来
4. 单人镜居中 0.50；多人无线索等距分布并报提示

## 四、不摆图层的情形

- **物证/细节特写**：正文没有人物或身体部位词时（针尖、绣绷、水珠），画面里本来没有人
- **人物特写**：全身抠图缩不出脸，先按近景 0.80 占位并报提示，重绘或换图后手调
- **空镜**：本镜视觉依据里没有具名人物
- **画外人物**：只出现在「画外：人物「X」」里的人

## 五、在 ComfyUI 里怎么用

完整操作顺序、判定标准、按钮依赖与排查表见
[从分镜到成片运行手册](ng-storyboard-runbook.md)。三条不能忘的：

- 角色卡的**卡名必须逐字等于 `@代称`**，否则提示词里的名字绑不到 `<Subject N>`
- 面板只管「摆在哪、多大」，**画面里是谁由角色卡决定**
- 顺序是 `Redraw all panels → Use in Director → Send to Director → Generate`，颠倒会送过去旧图或空图

## 六、已知失真（别指望脚本解决）

| 情形 | 脚本给出的 | 实际需要 |
|---|---|---|
| 过肩镜的前景肩 | 两个人物都按全身抠图摆位 | 前景肩要贴边放大、虚化，图层做不出来，进面板手调 |
| 半透纱幔、栏栅等遮挡层 | 不生成（无对应素材） | 用「+ Picture」加一层幔，或重绘时写进提示词 |
| 垂直高度（腾空、柱顶） | 识别到离地词时 `y` 抬 0.15 | 精确高度用 `- 图层：X y=0.45` |
| 动作连续性 | panel 只是首尾相接的分镜 | 跨镜动作仍按 [交接帧](shot-handoff.md) 与接力三件套 |
| 对白 | 不写 `spoken` | 多说话人按 [音轨可渲染性](voicetrack-renderability.md) 一镜一句（单轨档）；H3 generate 双声线档可 DUO 一镜 2~3 句，见 [SKILL.md](../SKILL.md) 档位分支 |
| 超过 9 镜 | 只写前 9 个面板 | 按场次拆成多张故事板 |

> **档位分支（2026-11-22 补全回灌）**：上文「一句一镜 / DUO 不得带台词」**只在 `source` + TTS 单轨音轨档成立**。若下游是 **H3 `generate` + 双声线参考音色档**，按 [镜型规则档位分支](../SKILL.md) 执行：对话戏禁用一句一镜，2~3 句对白合并为一个 DUO 双人同框中景（侧面机位、两人面对面），H3 自动按句间停顿分配两条声线；该档必挂双身份板 + 相对站位锚写进分镜/视频提示词/起始帧三处，镜长 ≥7s。依据：经验库 3.0 节 `[已验证·返工案例]`（EP001 16 镜 SOLO → 10 镜 DUO，单人漂移/并排/切换过频同时消失）。

## 七、自检

- 报告里出现了「认不出景别」「读不出画面哪侧」的镜，先补分镜再重跑，不要直接进面板
- 占位素材（`h3-example-*`）必须换成自己的图，否则画出来是示例人物
- `@代称` 必须与角色卡的**卡名**逐字一致，否则提示词里的名字绑不上 `<Subject N>`
- 面板总时长应等于分镜总时长；不等说明有镜缺 `时长` 且 `export_frames` 也不对
