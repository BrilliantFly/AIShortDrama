# H3 质量链编排

> 知识型 Skill（无 CLI），是「按步骤执行、不遗漏、可扩展」的**总调度入口**。
> 唯一权威清单：`H3-vibe-生产线操作手册.md` 2.x「质量链统一编排」表。
> 门禁脚本：`h3_lint/run_quality_chain.py`（`--stage n2|csv|delivery|all`）。

## 一、为什么需要总调度（防遗漏的真相）

**加一个"步骤"不等于不遗漏。** Skill 是知识型、无 CLI，靠 Agent 用 Skill 工具主动调用——"写进手册"只解决"知道该做什么"，没解决"当时有没有真的调"。实测教训：B 线写了诊断但没进提示词，两条 lint 视图字节完全相同。

防遗漏靠三层，缺一不可：

| 层 | 机制 | 防什么 | 在哪 |
|---|---|---|---|
| L1 定序 | 手册 2.x 编排表 | 不知道该调什么、顺序乱 | 已有 |
| L2 调度 | **本 Skill**（喊一句逐节点点名） | 靠人记、逐个点名会漏 | 本 Skill |
| L3 兜底 | `run_quality_chain.py` + 审片痕迹门禁 | 忘了做、做了没证据 | 脚本 |

**关键认知**：门禁只查"产物痕迹在不在"，查不了"是不是那个 Skill 写的"。**唯一硬证据是会话里的 `Skill(...)` 调用记录**——门禁全绿不等于 Skill 链路跑过。

## 二、铁律：不要把所有 Skill 堆到 N2

| Skill | 层 | 有效节点 |
|---|---|---|
| `导演运镜与机位构图` | 文本 | N2 内（storyboard 落盘后、video-prompts 前） |
| `H3跨层一致性锁` | 文本 | N2 写完提示词后、N7 装配前 |
| `H3成片质量审片` | 媒体 | **必须等 mp4**：N10 预览 / N12 出片 / N17 交付 |

把成片审片放 N2 会「无片可审」——它自己的 SKILL.md 明写「没有媒体时不用」。

## 三、执行清单（喊一句后按序走，逐项点名）

### 阶段 A · 走 N2
1. `Skill(short-drama-storyboard)` → `分镜.md` 骨架 + 冻结关键帧
2. `Skill(导演运镜与机位构图)` → 回写【诊断段】+ 全场情绪曲线（只改机位，不改职责/关键帧/时长）
3. `Skill(short-drama-video-prompts)` → `视频提示词.md` 六段式
4. 脚本：`run_quality_chain.py --stage n2`（5 项全 PASS 才交 N3）
5. 防呆：剔除诊断段后正文逐字一致（证明导演运镜没越权）

### 阶段 B · N7 前
6. `Skill(H3跨层一致性锁)` → 五道锁判定；回写只改提示词字段
7. 脚本：`run_quality_chain.py --stage csv`（镜号/拆段/装配体检）

### 阶段 C · 出片后
8. N10 预览出片 → `Skill(H3成片质量审片)`（4step 档：只判构图/动作/画风）
9. N12 正式出片 → `Skill(H3成片质量审片)`（25step 档：六维全判）

### 阶段 D · 交付
10. 脚本：`run_quality_chain.py --stage delivery`（段数/规格/尾段误交）
11. `check_review_report.py` → 确认 N10/N12 的审片报告产物存在（**防漏审片的痕迹门禁**）
12. 正片必须取 `seg_*.mp4` 分段版（归档版只落末段，1.1MB）

## 四、每阶段结束必做的自检

- 回头数一遍本阶段清单项，逐项确认有产物 **或** `Skill(...)` 调用记录；
- 门禁绿不能替代调用记录；缺任一项 → 当场补调，不交下一节点；
- 任一项 FAIL → 按返工路由回对应节点，不跳过。

## 五、怎么扩展（用户要求：后续可在这个步骤里补 Skill）

- **加脚本门禁**：在 `run_quality_chain.py` 顶部 `GATES` 加一条 `dict(stage, key, label, needed, build)`，`--list` 自动收录；再到本清单与手册编排表加一行。
- **加知识型 Skill**：本清单加一项（节点/调用/产物）+ 手册 2.x 编排表加一行。Skill 无 CLI，不进 `GATES`。
- **加新节点**：手册第 1 节总览表 + 2.x 编排表 + 本清单，三处同步。

## 六、与其它 Skill 的分工

本 Skill **只调度与点名**，不替代专业判定：镜头设计看 `导演运镜与机位构图`，四层一致性看 `H3跨层一致性锁`，验片六维看 `H3成片质量审片`。通用审查看 `short-drama-review`，tudou H3 规则只取规则与 `h3_lint/` 脚本、不装成独立 Skill。
