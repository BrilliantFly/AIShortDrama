# H3 成片质量审片

> 知识型 Skill（无 CLI）。由 Agent 在 N10 快出预览、N12 正式出片、收尾交付三个点主动调用。
> 定位：**复用** `short-drama-review` 的六档瑕疵分流，只补 H3 档位专属判据；不重写那套审查方法。

## 一、什么时候用 / 不做什么

- 用：已经有分段 mp4 或成片文件，且能读到对应 `分镜.md` / `视频提示词.md` / 装配回执。
- 不用：还没有媒体，只有文字方案（那是 `H3跨层一致性锁` 的活）。
- 不做：不改分镜、不改提示词、不换音频。只出结论 + 返工路由，交给对应负责技能改。

## 二、审片前必做的三件事

1. **先定档位**，不同档不能混判：4step 预览（960×544，允许残影、不判服装漂移为返工）；25step 正式（1344×768，身份/服装必须锁）；source 档（音频 fully_copy，口型以逐字台词为准）。
2. **拿到可核验证据**：首/中/尾抽帧、200% 放大脸部与道具、装配回执的 prompt_id、分段文件清单。没有证据就写「未观察」，不从文件存在或提示词推测画面正确（继承 `short-drama-review` 的证据纪律）。
3. **跑脚本门禁**（见第四节），把"诊断没落地"和"尾段误交"这类可确定性判定的先跑掉。

## 三、六维判据（H3 专属补充）

| 维度 | 4step 预览 | 25step 正式 | 返工路由 |
|---|---|---|---|
| 清晰度 | 允许轻微软残影、边缘糊；不判硬件级失败 | 1440p 以下不出片；暗部糊成死黑/亮部溢出判返工 | 重出 + 提高 step；不是 prompt 问题 |
| 身份服装 | **不判服装漂移为返工**（r2v 只锁主体语义，4step 遵循度低是已知上限） | 服装/发色漂移 = 返工；先查 Picture2 是否写全身份，再查是否 25step | 提示词层补 CAST → 回 N7 |
| 场景几何 | r2v 不锁首帧，逐镜几何漂移是机制硬限，预览可接受 | 几何漂移 = 返工；先试 `global.prompt` 场景锁，无效再上 i2v/首尾帧锁 | 工作流结构改动走 2_工作流 → 底座 → GUI 顺序 |
| 道具尺度 | 小道具放大成占画面 1/3 = 返工（3.5 节已实测） | 同左；check `natural size` 锚是否写进 detailed_description | 提示词层删 shallow-focus 特写句 → 回 N7 |
| 运镜落地 | 诊断写缓推、提示词写 no push = 冲突，必改 | 同左，且要抽帧确认镜头句真的生效 | 回 N2 用「H3跨层一致性锁」 |
| 声画口型 | 双声线槽位对、音色正确即过；4step 语音崩坏铁律只拦 generate+4步 | 逐字台词、口型、环境声（门内哄笑/继电器）三项都要听 | 回 N6 配音 / N7 音频槽 |

**已知机制硬限（不要误判为提示词没写好）**：
- `task_type=r2v` 的 `<Picture 1>` 只是「0 秒主体参考」，不是 i2v 首帧——起始帧图对、视频首帧错，不是图的问题。
- `global.prompt + commonEnabled` 能锁场景几何，但会压平段级站位差异；站位要写在段级 `detailed_description`，global 只写几何。
- 参考槽里放双人板，r2v 会把两张脸都画进画面 → 出现"同一人站着又坐着"。要减参考人数或改任务类型。
- 导演台 `SaveVideo` 归档版只落最后一段（1.1MB / 时长≈末段），**正片必须取 `seg_*.mp4` 分段版**。

## 四、脚本门禁（先跑，再人工看片）

```bash
# 运镜落地：诊断 vs 提示词镜头句 + 景别冲突 + 道具尺度风险
python h3_lint/check_camera_landing.py 分镜/分镜.md 分镜/视频提示词.md

# 跨层单一事实源：CAST+SET 是否继承、全身露脚、四槽顺序、[Shot N] 镜号
python h3_lint/check_castset_slot.py 分镜/视频提示词.md --expect-shots 5

# 成片交付：分辨率/fps/码率/尾段误交
python h3_lint/check_delivery_media.py out/seg_*.mp4 --archive out/整片.mp4 --expect 5
```

脚本只判"在不在、对不对齐"，判不了好不好看。六维里"好不好看"仍靠抽帧目视。

## 五、输出格式

写 `生产线/out/审片报告_<档位>_<日期>.md`，结构：
1. 执行事实（档位/分辨率/段数/回执/prompt_id）
2. 门禁结果（三个脚本的 RC 与逐项冲突）
3. 逐镜抽帧判定表（六维，PASS/FAIL/未观察）
4. 结论：PASS / REVISE，以及每条 REVISE 的返工路由（回 N2/N6/N7/结构改动）

## 六、与其它技能的分工

| 技能 | 分工 |
|---|---|
| `short-drama-review` | 通用六档瑕疵分流、剧本/分镜/剪辑层审查；本 Skill 只补 H3 档位与机制硬限 |
| `H3跨层一致性锁` | 出片前的文本层一致性；本 Skill 是出片后的媒体层验收 |
| `导演运镜与机位构图` | 镜头设计；本 Skill 只查"设计有没有落地"，不改设计 |
