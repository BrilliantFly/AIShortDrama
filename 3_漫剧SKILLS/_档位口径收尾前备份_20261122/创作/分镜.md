# 《同学会暗恋》EP001 · 分镜（走廊重逢）

> 场景：老系馆三楼走廊（夜、声控灯、报告厅门缝暖光）。全集 5 镜，单一场景，双人面对面。
> 台词以「」逐字登记；参考图用 PLAN- 挂图计划（供外部工具按序挂图），分配见各镜「输入参考图」。

## 场景锁定（SCENE BIBLE 提示）

- 走廊纵深沿画左右轴展开，报告厅门在画面右侧，门缝暖光恒定从右侧来。
- 走廊尽头窗户在画左远景，暗蓝色夜色，不透人影。
- 天花板声控灯三段：近门段亮（暖白）、中段暗、尽头段半暗；灯只在 S004 末→S005 初发生变化（灭→重新亮）。
- 墙面：画右墙面贴系史展板（含 2013 毕业合影展板，画面中不可读文字）；画左是教室门与消防栓。
- 两人站位：沈屿恒在画左/走廊中段，林晚恒在画右/靠报告厅门侧，面对面左右相对，永不同侧并排。

## SHOT-EP001-001 · 拐角相遇

- 景别/焦段：全景 → 中景，24mm，随人缓推。
- 出场设定：沈屿（全身，端两杯汽水）、林晚（全身，推安全门进，手机照明亮）。
- 输入参考图：
  - PLAN-CORRIDOR（顺序：1）· 场景板《IMG-CORRIDOR.png》用途：场景
  - PLAN-LW-SHEET（顺序：2）· 女主三视图《IMG-LW-SHEET.png》用途：角色
  - PLAN-SD-SHEET（顺序：3）· 男主三视图《IMG-SD-SHEET.png》用途：角色
- 起始帧：走廊空镜，沈屿背对镜头站在拐角，林晚刚推开安全门，门缝光切入。
- 动作过程：林晚推门而入，手机光扫到沈屿侧脸 → 沈屿回头，两人隔走廊对望 → 各自顿住半步
- 终点：两人相距四步对望，谁都没动，门在林晚身后合上。
- 时长：6s

## SHOT-EP001-002 · 好久不见

- 景别/焦段：中近景双人，35mm，固定。
- 出场设定：沈屿（胸上）、林晚（胸上），面对面左右相对。
- 输入参考图：
  - PLAN-CORRIDOR（顺序：1）· 场景板《IMG-CORRIDOR.png》用途：场景
  - PLAN-LW-SHEET（顺序：2）· 女主三视图《IMG-LW-SHEET.png》用途：角色
  - PLAN-SD-SHEET（顺序：3）· 男主三视图《IMG-SD-SHEET.png》用途：角色
- 起始帧：两人对望，林晚手机灯还亮着，光晃在沈屿脸上。
- 动作过程：林晚手机灯垂下去 → 她开口「好久不见。」→ 沈屿递出一杯汽水
- 终点：沈屿的手悬在两人之间递汽水，林晚目光落在杯上。
- 台词：林晚：「好久不见。」
- 时长：5s

## SHOT-EP001-003 · 你现在做本行了

- 景别/焦段：越肩对切合一镜，50mm，轻微缓推至双人中景。
- 出场设定：沈屿、林晚（胸上→中景）。
- 输入参考图：
  - PLAN-CORRIDOR（顺序：1）· 场景板《IMG-CORRIDOR.png》用途：场景
  - PLAN-LW-SHEET（顺序：2）· 女主三视图《IMG-LW-SHEET.png》用途：角色
  - PLAN-SD-SHEET（顺序：3）· 男主三视图《IMG-SD-SHEET.png》用途：角色
- 起始帧：林晚指尖碰到递来的汽水杯，两人都缩了一下。
- 动作过程：林晚接杯未开 → 三句对白往来（做本行/我都记得/忘了路）→ 沈屿笑意停在嘴角
- 终点：两人各持一杯汽水对望，沈屿的笑意停在嘴角，走廊灯在两人头顶。
- 台词：沈屿：「你现在做本行了？插画。」／林晚：「嗯，勉强算。你还记这个。」／沈屿：「我都记得。」
- 时长：10s

## SHOT-EP001-004 · 坏掉的灯（母题物件）

- 景别/焦段：特写→近景，85mm，固定。
- 出场设定：沈屿的手与旧钥匙扣（特写）；林晚（近景，画右听）。
- 输入参考图：
  - PLAN-KEYCHAIN（顺序：1）· 道具板《IMG-KEYCHAIN.png》用途：道具
  - PLAN-SD-SHEET（顺序：2）· 男主三视图《IMG-SD-SHEET.png》用途：角色
  - PLAN-LW-SHEET（顺序：3）· 女主三视图《IMG-LW-SHEET.png》用途：角色
- 起始帧：声控灯灭，走廊暗下来，林晚侧影靠近沈屿半步，特写他的手在口袋里。
- 动作过程：他摸出旧钥匙扣按第一下灯没亮 → 按第二下仍没亮 → 抬眼说「跟大三那年一样，坏了我也给你留着」
- 终点：林晚近景侧耳听着，走廊只剩门缝暖光勾出两人轮廓。
- 台词：沈屿：「这灯，早坏了。跟大三那年一样，坏了我也给你留着。」
- 时长：8s

## SHOT-EP001-005 · 灯重新亮起

- 景别/焦段：双人中景，35mm，固定。
- 出场设定：沈屿、林晚（腰部以上），面对面。
- 输入参考图：
  - PLAN-CORRIDOR（顺序：1）· 场景板《IMG-CORRIDOR.png》用途：场景
  - PLAN-LW-SHEET（顺序：2）· 女主三视图《IMG-LW-SHEET.png》用途：角色
  - PLAN-SD-SHEET（顺序：3）· 男主三视图《IMG-SD-SHEET.png》用途：角色
- 起始帧：暗廊中钥匙扣从沈屿掌心转入林晚掌心。
- 动作过程：林晚攥紧钥匙扣 → 声控灯「啪」重新亮 → 两人灯下对望，同时笑出来 → 门内哄笑声涌起
- 终点：两人笑着对望，各自手里一杯汽水，林晚掌心攥着旧钥匙扣。
- 时长：6s

## 审片清单（分镜自检）

- 转场：S001→S002→S003→S004→S005 全部硬切（同场景连戏），无叠化。
- 母题：旧钥匙扣首现于 S004（人物台词点名「坏了我也给你留着」），S005 承接（林晚攥紧）。
- 灯光变化仅发生在 S004→S005（灭→亮），其余镜恒定。
- 每场较场首均有可见变化（站位/道具/光线至少一项）。
