# 拉片手册 → 分镜的编译规程（L8）

> 输入是拉片材料（手册、逐镜表、参考视频），输出是能过 lint 的分镜稿。第四、五轮手册编译
> 验证发现：直接「照抄」会在四个位置系统性坏掉——时长、运镜、声音、字段归属。本文是四步规程，
> 每步给出判据与去向。

## 第 0 步：确认素材形态

拉片材料通常只有两类信息是**硬的**：镜号顺序、时长。其余（景别、运镜、声音、意图）是
**结果描述**，要逐条翻译成生成端可用的参数。先问一句：这镜在原片里的职责是什么？答不出
就别翻——抄形态没有意义。

## 第 1 步：时长——量化 + 换算（详细判据见 voicetrack-renderability.md「可剪点」）

- 原片时长 ÷ 24 得帧数，对齐 17 网格（102/119/…/204），**夹进 [102, 204]**
- **低于 102 帧的短镜（经典片 31% 是这类）不压段长**：写 `可剪点：动作于 X.Xs 完成，其后保持`，
  生成一段合法长度，成片再剪——lint L6 会拦「照抄的短时长」
- 一镜长于 9.21s 按可见状态闭合点拆（换气点、落泪点、转身完成点都是标准缝）
- 记住：**生成段长 ≠ 成片镜长**。两镜之间靠交接（末帧抽帧 / 同 seed 重出）接住

## 第 2 步：运镜——查替代写法库（详见 camera-move-rewrites.md）

按 minimax-h3 的可靠性边界逐镜判：可靠只有机位描述、小幅推拉、时间分配句。
横移/跟拍/环绕/甩镜在库里各给 2 种改写（拆固定机位 / 拆起终帧），手册那镜怎么写就怎么换。
判据是**机位能摆出来**，不是「描述了运动」。

## 第 3 步：声音——三层分流（详见 voice-layer-craft.md）

- 画内/环境 → 五槽位写进 `声音` 字段，必须带空间词
- 配乐指令 → 后期；声音内容从画面读出来补（手册 7/16 镜只有配乐，全部可补，逐镜实表在
  voice-layer-craft.md 第三节）
- 有台词的镜按「台词 + 括号估时 + 环境底」三件套写

## 第 4 步：字段归属——别把观众信息塞进生成字段

拉片语言（「快切节奏」「情绪递进」「一镜到底」）是**给编排人的**，翻译成 drama 字段时：

| 拉片说法 | 落进哪个字段 |
|---|---|
| 景别/机位 | `景别/机位`（写机位语言：谁前景谁后景、画面哪侧） |
| 位置关系 | 场景站位块（锚点 + 屏幕方向）+ 各镜起点/终点 |
| 运镜 | `运镜`（只写可靠词；不可靠的进第 2 步换写法） |
| 声音 | `声音`（三层分流） |
| 配乐/情绪 | `目的` 或制作备注（不进 `声音`） |
| 台词 | `声音` 里「」原文 + 括号估时；镜型 SOLO/OTS 必标 |

## 第 5 步：过 lint 再定稿

`storyboard_lint.py` 会拦四类照抄病：短时长（L6）、纯配乐声音（M2-①）、有台词零环境底
（M2-②）、来源场次 ID 解析不出（格式：`SC01「短引文」`，ID 必须字母+数字紧挨）。
lint 过了才算编译完成，没过按提示回对应步骤。

## 反推场次 ID 与镜号

拉片材料常没有场次概念。按空间单元反推：同一地点 + 同一光态 = 一个场次
（`SC01`、`SC02`…），镜号沿用拉片序号（`SHOT-SC01-001`）。判据是「机位转过去还是同一个
地方吗」——是就同场，不是就另立。

## 边界

- 手册一句话点评类片段（无逐镜参数）不构成编译输入，强行编就是创作——按 drama 正常流程
  从剧本走
- 编译产物是**草稿**：运镜与声音两步的改写保住的是「可生产性」，与原片的观感有已知差距
  （详见 ng-storyboard-export.md 七类失真、camera-move-rewrites.md 各条代价）
