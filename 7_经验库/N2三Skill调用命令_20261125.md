## 2. 安装命令（WorkBuddy）

### 2.1 项目级（推荐，随工作区走）

把三个目录整个复制到工作区的 `.workbuddy/skills/`，保留 `SKILL.md` 在顶层：

```bash
# <工作区根> = WorkBuddy 当前打开的工作区；<资料库根> = 本仓库
WS=<工作区根>
REPO=<资料库根>

mkdir -p "$WS/.workbuddy/skills"

cp -r \
  "$REPO/3_漫剧SKILLS/2_分镜/1_主SKILLS/drama-skills-main/drama-skills-main/skills/short-drama-storyboard" \
  "$REPO/3_漫剧SKILLS/2_分镜/1_主SKILLS/drama-skills-main/drama-skills-main/skills/short-drama-video-prompts" \
  "$REPO/3_漫剧SKILLS/2_分镜/2_其他/导演运镜与机位构图" \
  "$WS/.workbuddy/skills/"
```

本机值请在运行时按实际填写，**不要写死盘符**（换电脑盘符会变）：

```bash
# Git Bash / Linux / macOS：在仓库根目录执行，自动取当前路径
REPO="$(pwd)"
WS="<当前 WorkBuddy 工作区根的绝对路径>"   # 按实际填写，勿硬编码盘符

# Windows PowerShell（在仓库根目录执行）：
#   $REPO = (Get-Location).Path
#   $WS   = "<当前 WorkBuddy 工作区根>"
```

如果你直接以仓库根作为 WorkBuddy 工作区，则令 `WS=$REPO`，安装到 `<资料库根>/.workbuddy/skills/`，这样 clone 到别的电脑也跟着走。

### 2.2 用户级（所有项目可用）

```bash
cp -r \
  "<资料库根>/3_漫剧SKILLS/2_分镜/1_主SKILLS/drama-skills-main/drama-skills-main/skills/short-drama-storyboard" \
  "<资料库根>/3_漫剧SKILLS/2_分镜/1_主SKILLS/drama-skills-main/drama-skills-main/skills/short-drama-video-prompts" \

```

Windows 对应用户目录：`C:/Users/<用户名>/.workbuddy/skills/`。导演运镜目录自带的 `安装说明.txt` 写的就是这条路径。

- **新开一个会话**：Skill 列表在会话启动时加载，当前会话内复制不会立即出现在可用列表。
- 新会话先验证：问一句「列出可用 Skill，确认 `short-drama-storyboard`、`导演运镜与机位构图`、`short-drama-video-prompts` 在不在」。
- 若仍不在，到技能管理/设置里启用该 Skill；不要以为复制完就等于能调用。

## 4. Agent 内部调用命令（核心）

> 这是 Agent 用的工具调用，不是创作者手敲的 shell 命令。
> 顺序硬约束：步骤 2 必须在步骤 1 落盘后、步骤 3 之前。

```text
# 步骤 1：drama 主干出分镜骨架
Skill(skill="short-drama-storyboard",
      args="按 H3-vibe N2，读取 剧集/<EP>/剧本.md + 视觉设定.md + short-drama.json；
            输出 剧集/<EP>/分镜.md，含 ## SHOT-...、冻结关键帧提示词、输入参考图槽位；
            不生成媒体")

# 步骤 2：导演运镜做镜头顾问（语义自动，无 CLI）
Skill(skill="导演运镜与机位构图",
      args="只读刚落盘的 剧集/<EP>/分镜.md；
            逐镜追加【导演运镜诊断】段 + 全场情绪曲线；
            只改机位/运镜/六维/情绪处方；
            禁止改镜头职责、连续性、冻结关键帧正文、时长；
            回写后剔除诊断段应与回写前逐字一致")

# 步骤 3：drama 主干出视频提示词
Skill(skill="short-drama-video-prompts",
      args="读取 剧集/<EP>/分镜.md；按 MiniMax H3 方言输出 视频提示词.md；
            ## MOTION-... 对齐 ## SHOT-...；写六段式、Audio 绑定、输入参考图顺序；
            不生成媒体、不改分镜边界")
```

步骤 4 是脚本自动，不是 Skill：

```bash
python h3_lint/md_to_h3_lint.py 分镜/视频提示词.md \
  -o out/视频提示词_lint视图.html --lint
```

## 6. 怎么确认「真调了 Skill」

| 证据层级 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 会话中的 `Skill(...)` 工具调用记录 | **唯一硬证据**：确实调用了对应 Skill | — |
| `check_n2_skills.py` PASS | 产物里有诊断段与情绪曲线 | 不能证明是 Skill 写的，手写也能过 |
| `storyboard_lint.py` / `md_to_h3_lint.py` PASS | 格式与契约合规 | 不能证明调用链发生 |
| 剔除诊断段后正文逐字一致 | 导演运镜没越权改主干 | 不能证明调用链发生 |

因此验收顺序是：**先看工具调用记录 → 再看四重门禁 → 最后做防呆 diff**。只跑门禁全绿，不等于 Skill 链路跑过。
